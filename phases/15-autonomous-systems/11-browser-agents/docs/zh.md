# 浏览器智能体与长周期网页任务

> ChatGPT 智能体（2025 年 7 月）将 Operator 与深度研究合并为一个浏览器/终端智能体，并将 BrowseComp 的 SOTA 提升至 68.9%。OpenAI 于 2025 年 8 月 31 日关闭了 Operator —— 产品层面的整合。Anthropic 收购 Vercept 使 Claude Sonnet 在 OSWorld 上的成绩从低于 15% 跃升至 72.5%。WebArena-Verified（ServiceNow，ICLR 2026）修复了原始 WebArena 中 11.3 个百分点的假阴性率，并发布了包含 258 个任务的 Hard 子集。数字是真实的。攻击面同样真实：OpenAI 的准备工作负责人公开表示，针对浏览器智能体的间接提示注入“不是一个可以完全修补的 bug”。已记录的 2025–2026 攻击包括：Tainted Memories（Atlas CSRF）、HashJack（Cato Networks）以及 Perplexity Comet 中的一键劫持。

**类型：** 学习  
**语言：** Python（标准库，间接提示注入攻击面模型）  
**前置要求：** 第 15 阶段 · 10（权限模式），第 15 阶段 · 01（长周期智能体）  
**时间：** ~45 分钟

## 问题

浏览器智能体是一种长周期智能体，它读取不受信任的内容并执行有影响力的操作。智能体访问的每个页面都是用户未编写的输入。每个页面上的每个表单都是一个潜在的命令通道。2025–2026 的攻击语料表明，这并非假设：Tainted Memories 允许攻击者通过精心构造的页面将恶意指令绑定到智能体的记忆；HashJack 将命令隐藏在智能体访问的 URL 片段中；Perplexity Comet 劫持则通过一次点击即可完成。

防御图景令人不安。OpenAI 的准备工作负责人直言不讳：间接提示注入“不是一个可以完全修补的 bug”。这是因为攻击存在于智能体读取与行动的边界，而这一边界在架构上是模糊的 —— 模型读取的每一个 token 原则上都可能被解读为指令。

本课将命名攻击面，命名基准测试格局（BrowseComp、OSWorld、WebArena-Verified），并构建一个最小化的间接提示注入场景，以便你在第 14 课和第 18 课中推理实际的防御手段。

## 概念

### 2026 年的格局，每段一句话概括每个系统

**ChatGPT 智能体（OpenAI）。** 于 2025 年 7 月发布。整合了 Operator（浏览）和 Deep Research（数小时研究）。于 2025 年 8 月 31 日关闭了独立的 Operator。在 BrowseComp 上达到 SOTA 68.9%；在 OSWorld 和 WebArena-Verified 上也有强劲表现。

**Claude Sonnet + Vercept（Anthropic）。** Anthropic 收购 Vercept 专注于计算机使用能力。将 Claude Sonnet 在 OSWorld 上的成绩从低于 15% 提升至 72.5%。Claude Computer Use 以工具 API 形式提供。

**Gemini 3 Pro + Browser Use（DeepMind）。** Browser Use 集成提供了计算机使用控制；FSF v3（2026 年 4 月，第 20 课）专门追踪 ML 研发领域的自主性。

**WebArena-Verified（ServiceNow，ICLR 2026）。** 修复了一个有据可查的问题：原始 WebArena 存在约 11.3% 的假阴性率（任务标记为失败但实际上已解决）。Verified 版本使用人工筛选的成功标准重新评分，并增加了 258 个任务的 Hard 子集（ICLR 2026 论文，openreview.net/forum?id=94tlGxmqkN）。

### BrowseComp vs OSWorld vs WebArena

| 基准测试 | 衡量内容 | 时间跨度 |
|---|---|---|
| BrowseComp | 在时间压力下从开放网络中查找特定事实 | 分钟 |
| OSWorld | 智能体操作完整桌面（鼠标、键盘、Shell） | 数十分钟 |
| WebArena-Verified | 模拟网站中的事务性网页任务 | 分钟 |
| Hard 子集 | 具有多页面状态转换的 WebArena-Verified 任务 | 数十分钟 |

不同维度。高 BrowseComp 分数表示智能体能找到事实；并不意味着智能体可以预订航班。OSWorld 分数更接近“它能在我的桌面上工作吗”。WebArena-Verified 更接近“它能完成一个流程吗”。任何生产决策都需要匹配任务分布的基准测试。

### 攻击面，逐一命名

1. **间接提示注入。** 不受信任的页面内容包含指令。智能体读取它们。智能体执行它们。公开示例：2024 年 Kai Greshake 等人的工作，2025 年 Tainted Memories 论文，2026 年 HashJack（Cato Networks）。
2. **URL 片段 / 查询注入。** 被爬取 URL 的 `#fragment` 或查询字符串包含命令。从不可见地渲染；仍然在智能体的上下文内。
3. **记忆绑定攻击。** 页面指示智能体写入持久化记忆（第 12 课涵盖持久状态）。下一个会话中，记忆在没有可见触发器的情况下触发载荷。
4. **针对已认证会话的 CSRF 型攻击。** Tainted Memories 类别：智能体在某处已登录；攻击者的页面发出状态更改请求，智能体使用用户的 cookie 执行这些请求。
5. **一键劫持。** 视觉上无害的按钮携带一个载荷，智能体会跟随执行。Comet 类别。
6. **智能体主机表面的内容安全策略漏洞。** 渲染层和工具层本身可能成为攻击向量；浏览器中的浏览器智能体栈非常宽。

### 为什么“不能完全修补”

该攻击与智能体的能力同构。智能体必须读取不受信任的内容才能完成工作。智能体读取的任何内容都可能包含指令。智能体遵循的任何指令都可能与用户的实际请求不一致。防御措施（信任边界、分类器、工具白名单、针对有影响力操作的人类在环）提高了攻击成本并降低了其爆炸半径。它们无法关闭整个攻击类别。

这与第 8 课中 Lob 定理的推理模式相同：智能体无法证明下一个 token 是安全的；它只能建立一个使不安全 token 更易被检测的系统。

### 实际部署的防御姿态

- **读/写边界。** 读取从不产生影响力。写入（提交表单、发布内容、调用具有副作用的工具）如果发起内容来自信任边界之外，则需要重新获得人类批准。
- **每个任务的工具白名单。** 智能体可以浏览；除非该工具被明确启用用于该任务，否则不能发起电汇。第 13 课涵盖预算。
- **会话隔离。** 浏览器智能体会话仅使用限定范围的凭据运行。无生产认证，无个人电子邮件。保留每个 HTTP 请求的日志以供审计。
- **内容消毒器。** 在将获取的 HTML 拼接到模型上下文之前，剥离已知有害模式。（减少简单攻击；无法阻止复杂载荷。）
- **对影响力操作的人类在环。** 提议-然后-提交模式（第 15 课）。
- **记忆上的金丝雀令牌。** 如果记忆条目被触发，用户会看到它（第 14 课）。

## 使用它

`code/main.py` 模拟一个微型浏览器智能体对三个合成页面的运行。一个页面是良性的，一个在可见文本中包含直接的提示注入块，一个包含 URL 片段注入（不可见但在智能体的上下文中）。脚本展示了 (a) 幼稚智能体会做什么，(b) 读/写边界能捕获什么，(c) 消毒器能捕获什么，(d) 两者都未能捕获什么。

## 交付它

`outputs/skill-browser-agent-trust-boundary.md` 描述了一个拟议的浏览器智能体部署范围：它接触哪些信任区域，它被授权写入什么，以及在首次运行之前必须部署哪些防御措施。

## 练习

1. 运行 `code/main.py`。识别消毒器能捕获但读/写边界不能捕获的攻击，以及只有读/写边界能捕获的攻击。

2. 扩展消毒器以检测一类 HashJack 风格的 URL 片段注入。在包含合法片段的良性 URL 上测量误报率。

3. 选择一个你知道的真实浏览器智能体工作流（例如“预订航班”）。列出每次读取和每次写入。标记哪些写入需要人类在环并说明原因。

4. 阅读 WebArena-Verified ICLR 2026 论文。识别一个原始 WebArena 评分不可靠的任务类别，并解释 Verified 子集如何解决该问题。

5. 为浏览器智能体环境设计一个记忆金丝雀。你会存储什么？存储在哪里？什么触发警报？

## 关键术语

| 术语 | 人们常说的 | 实际含义 |
|---|---|---|
| 间接提示注入 | “有问题的页面文本” | 智能体读取的页面中不受信任的内容包含指令，智能体执行这些指令 |
| Tainted Memories | “记忆攻击” | 智能体将攻击者提供的指令写入持久化记忆；下一个会话触发 |
| HashJack | “URL 片段攻击” | 载荷隐藏在 URL 片段/查询字符串中，在智能体上下文中但不可见渲染 |
| 一键劫持 | “有问题的按钮” | 可见的交互界面携带一个后续载荷，智能体执行 |
| BrowseComp | “网页搜索基准测试” | 在开放网络中查找特定事实；分钟级时间跨度 |
| OSWorld | “桌面基准测试” | 完全操作系统控制；多步 GUI 任务 |
| WebArena-Verified | “修复后的网页任务基准测试” | ServiceNow 重新评分的 WebArena，包含 Hard 子集 |
| 读/写边界 | “副作用门控” | 读取从不产生影响力；如果内容来自信任边界之外，写入需要重新批准 |
