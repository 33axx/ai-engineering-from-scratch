# 面向LLM的群体优化（PSO、ACO）

> 生物启发优化正让LLM重新焕发生机。**LMPSO**（arXiv:2504.09247）使用PSO，其中每个粒子的速度是一个提示，LLM生成下一个候选；适用于结构化序列输出（数学表达式、程序）。**Model Swarms**（arXiv:2410.11163）将每个LLM专家视为模型权重流形上的PSO粒子，报告在9个数据集上对12个基线实现了**13.3%的平均提升**，仅用了200个实例。**SwarmPrompt**（ICAART 2025）将PSO与灰狼算法混合用于提示优化。**AMRO-S**（arXiv:2603.12933）是基于ACO的信息素专家用于多智能体LLM路由——**4.7倍加速**、可解释的路由证据、解耦推理与学习的质量门控异步更新。本课程在提示参数空间上实现PSO，在智能体路由上实现ACO，评估这些经典算法为什么适合LLM时代，以及何时不适合。

**类型:** 学习+构建
**语言:** Python（标准库）
**先修条件:** 阶段16·09（并行群体网络），阶段16·14（共识与BFT）
**时间:** 约75分钟

## 问题

你有一个在任务评估中得分62%的提示。你想要改进它。天真的做法是无梯度的手动调整，但这扩展性很差。强化学习需要奖励信号和足够的展开来训练。通过提示进行反向传播实际上是不可能的——提示是一个离散字符串，而非可微参数。

经典生物启发优化——适用于连续搜索空间的PSO，适用于路径选择的ACO——正是为此场景设计的：无梯度、基于种群、每次评估成本低。将它们与LLM配对用于无梯度搜索步骤，你就得到了一个出奇实用的优化器。

同样的模式适用于多智能体系统中的智能体*路由*。ACO式的信息素轨迹记录了哪个智能体对哪类任务表现最佳，让路由器利用该轨迹，并通过信息素衰减以便重新发现路由。

## 概念

### PSO回顾（Kennedy & Eberhart 1995）

粒子群优化：连续搜索空间中的粒子群。每个粒子有位置`x_i`和速度`v_i`。每次迭代：

```
v_i <- w * v_i + c1 * r1 * (p_best_i - x_i) + c2 * r2 * (g_best - x_i)
x_i <- x_i + v_i
evaluate fitness(x_i)
update p_best_i if improved
update g_best if global best
```

其中`p_best`是粒子自身最优，`g_best`是群体最优，`w, c1, c2`是惯性、认知和社会权重，`r1, r2`是随机因子。

### PSO在LLM输出上——LMPSO

arXiv:2504.09247将PSO适配到LLM生成的结构化输出（数学表达式、程序）。每个粒子是一个候选输出。速度是描述如何修改当前输出以接近个体/全局最优的*提示*。LLM根据速度提示生成新的输出。速度的"惯性"是类似"做小的增量变化"的提示。

这在以下情况下效果良好：
- 输出是结构化的（可解析、可评估）。
- 适应度是自动的（测试运行、算术评估）。
- 种群规模小（约10-30个粒子），使得LLM总调用保持可控。

当适应度需要人工审查时效果不佳——每次迭代的成本变得过高。

### Model Swarms

arXiv:2410.11163将PSO从输出层移至*模型*层。每个"粒子"是一个专家LLM（参数）。群体通过无梯度更新将参数移向集体最优。报告：在9个数据集上对12个基线实现了13.3%的平均提升，每次迭代仅用200个实例。

关键洞察在于LLM专家模型在一个共享参数流形（适配器权重、LoRA增量）上已经彼此接近。在这个低维子空间上的PSO既廉价又高效。

### ACO回顾（Dorigo 1992）

蚁群优化：蚂蚁遍历图；每条路径有信息素踪迹。蚂蚁移动概率由信息素强度决定。完成任务后，蚂蚁根据解的质量按比例沉积信息素。信息素随时间衰减。

### AMRO-S——用于智能体路由的ACO

arXiv:2603.12933使用ACO进行多智能体路由。每种任务类型是一个"目的地"；每个智能体是一条可能的路径。信息素增强产生良好输出的路径。关键贡献：

- **可解释的路由证据。** 信息素强度是人可读的信号。
- **质量门控异步更新。** 信息素仅在质量检查通过后更新，解耦推理与学习。
- **4.7倍加速**在多智能体路由基准上。

质量门很重要：没有它，快速但错误的智能体会积累信息素，系统会锁定在糟糕的路由上。

### 何时在LLM中使用PSO/ACO

**使用PSO当：**
- 搜索空间是连续的或映射到连续参数（提示嵌入、LoRA权重、数值生成参数）。
- 适应度评估廉价且自动。
- 种群可以很小（10-30）。

**使用ACO当：**
- 你有一个路由或路径选择问题。
- 决策随时间的推移而加强（相同的任务类型反复出现）。
- 你需要路由决策的可解释证据。

**两者都不使用时：**
- 适应度需要人工审查（每次迭代成本太高）。
- 搜索空间是离散且组合的，PSO不适用（改用遗传算法）。
- 实时决策需要严格的延迟（PSO/ACO相对于单次启发式方法收敛慢）。

### 为什么生物启发依然胜出

基于梯度的方法需要可微信号。LLM输出和路由决策不易微分。伪梯度方法（强化学习路由器、DPO式提示调谐器）有效但需要昂贵的训练。

PSO和ACO只需要一个*评估器*函数。如果你能对候选输出或路由决策进行评分，就可以在这个空间上优化。这大大降低了适用门槛。

### 实际限制

- **种群预算。** N个粒子 × T次迭代 × 每次评估成本。对于每次调用约$0.02的LLM评估，一个20粒子PSO运行50次迭代的成本约为$20。请相应规划。
- **探索与利用。** 信息素衰减率和PSO惯性之间存在权衡；衰减太快→忘记解；太慢→停留在早期局部最优。
- **灾难性漂移。** 如果适应度景观发生变化（新的数据分布），两种算法都可能收敛后发散。监控最佳适应度的稳定性。

## 构建它

`code/main.py`实现了：

- `LMPSO`——对数值提示参数（温度、top_k权重）进行PSO。每个粒子的"LLM生成"被模拟为脚本化的适应度函数。运行算法30次迭代并显示g_best收敛。
- `AMRO_S`——ACO风格路由。3个智能体，4种任务类型，信息素矩阵，100个路由任务。打印（任务类型→智能体选择）随时间变化的分布，以显示轨迹形成。
- 对比：在相同任务流上随机路由与ACO路由。衡量质量和延迟。

运行：

```
python3 code/main.py
```

预期输出：
- LMPSO：g_best适应度在30次迭代中从随机提升到接近最优。
- AMRO-S：信息素表在每个任务类型上稳定到正确的智能体；ACO路由在质量上优于随机约30-40%，同时降低了延迟（重试次数更少）。

## 使用它

`outputs/skill-swarm-optimizer.md`帮助在PSO、ACO、遗传算法和基于梯度的优化器之间为LLM/智能体优化做出选择。

## 部署它

- **从小开始。** 10-20个粒子，20-50次迭代。仅在收敛曲线显示明显收益时才扩大规模。
- **记录每次迭代的信息素或g_best。** 没有轨迹调试群体优化器是痛苦的。
- **质量门控更新。** 特别是对于ACO路由：快速但错误的智能体不得累积信息素。
- **在分布偏移时重置衰减。** 当你的评估分布发生变化时，陈旧的信息素已经失效；重置或暂时加倍衰减率。
- **限制每次迭代成本。** 输出每次迭代成本指标。每次迭代成本$500但仅提升0.5%的PSO是不可交付的。

3. 为AMRO-S添加质量门：仅在评估分数>0.7的运行中沉积信息素。这与无门控版本相比如何改变收敛？

5. 阅读AMRO-S（arXiv:2603.12933）。实现解耦的"推理快速路径"与异步信息素更新。这如何改变持续负载下的系统延迟？

## 关键术语

| 术语 | 大家说的 | 实际含义 |
|------|----------|----------|
| PSO | "Particle Swarm Optimization" | Kennedy-Eberhart 1995。基于种群的免梯度优化器。 |
| ACO | "Ant Colony Optimization" | Dorigo 1992。通过信息素轨迹进行路径/路由优化。 |
| LMPSO | "PSO with LLM generation" | arXiv:2504.09247。速度是提示；LLM产生候选。 |
| Model Swarms | "PSO on expert weights" | arXiv:2410.11163。在模型参数子空间上进行免梯度更新。 |
| AMRO-S | "ACO for agent routing" | arXiv:2603.12933。任务类型×智能体的信息素矩阵。 |
| p_best / g_best | "Personal / global best" | 每个粒子和整个群体目前找到的最佳解。 |
| Pheromone | "Routing memory" | 边上的强度；随时间衰减；根据质量沉积。 |
| Quality-gated update | "Only learn from good runs" | 信息素沉积以质量检查为条件。 |
| Catastrophic drift | "Distribution shift" | 适应度景观变化；旧的p_best和信息素过时。 |
