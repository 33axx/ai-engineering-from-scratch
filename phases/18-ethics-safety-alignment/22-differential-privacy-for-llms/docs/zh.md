# LLM 的差分隐私

> DP-SGD 仍是标准方法——注入噪声的梯度更新提供形式化的 (ε, δ) 保证。计算、内存和效用方面的开销相当大；参数高效的 DP 微调（LoRA + DP-SGD）是 2025 年的常见配置（ACM 2025）。两方面的证据存在矛盾：基于金丝雀（canary）的成员推断（Duan 等人，2024）报告了对语言模型效果有限；训练数据提取（Carlini 等人，2021；Nasr 等人，2025）则恢复了大量逐字记忆。2025 年 3 月的化解方法（arXiv:2503.06808）：差距在于测量对象——插入的金丝雀 vs “最易提取”的数据。新的金丝雀设计使得无需影子模型即可进行基于损失的成员推断，并首次对在实际数据上训练且具有实际 DP 保证的 LLM 进行了非平凡的 DP 审计。替代方案：PMixED（arXiv:2403.15638）——通过基于下一个 token 分布的专家混合在推理时进行私有预测；DP 合成数据生成（Google Research 2024）。新兴攻击：通过 LLM 反馈进行差分隐私逆转——置信度分数泄露。

## 学习目标

## 问题所在

LLM 会记忆。Carlini 等人 2021 年证明，生产环境下的语言模型能按需逐字复现训练文本。差分隐私是形式化的防御手段：通过训练使输出对任意单个训练样本都证明不敏感。2024-2025 年的证据表明 DP-SGD 是必要的，但实际部署的 ε 值可能与威胁模型并不匹配。

## 概念

### (ε, δ)-差分隐私

随机化算法 M 是 (ε, δ)-DP 的，如果对于任意两个仅相差一个样本的数据集以及任意事件 S：
P(M(D) ∈ S) ≤ e^ε * P(M(D') ∈ S) + δ。

解释：输出分布足够接近（由 ε 参数化），以至于任何单个个体的贡献都无法被可靠推断，除非概率为 δ。

### DP-SGD

Abadi 等人 2016 年提出。标准步骤：
1. 采样一个小批量。
2. 计算逐样本梯度。
3. 将每个逐样本梯度裁剪到阈值 C。
4. 对裁剪后的梯度求和，并添加标准差为 σ * C 的高斯噪声。
5. 使用带噪声的和来更新参数。

隐私成本由会计（矩会计、Rényi DP 会计）跟踪。LLM 文献中报告的 ε 值因威胁模型、数据敏感性和效用目标而有很大差异；没有通用的“安全”默认 ε。已发表的例子大致涵盖 ε ≈ 1–10 的范围（在某些 LLM 训练设置中），但这些只是示例性的，并非推荐默认值。较低的 ε 通常需要更多噪声，并可能导致更大的效用损失。

### LoRA + DP-SGD

对前沿模型进行完全的 DP-SGD 是不可行的。LoRA（Hu 等人 2022）将梯度更新限制在小型适配器上，减少了逐样本梯度的存储。LoRA + DP-SGD 是 2025 年的常见配置。DP 保证适用于适配器；基础模型保持固定。

### 2024-2025 年的矛盾

两条证据线索：

- **金丝雀成员推断（Duan 等人 2024）。** 在训练数据中插入唯一的金丝雀，测量成员推断攻击者能否识别它们。报告对语言模型效果有限。表明成员推断很困难。
- **训练数据提取（Carlini 2021，Nasr 等人 2025）。** 用前缀提示模型，测量模型是否恢复训练数据中的逐字文本。报告了大量记忆。表明成员推断在相关意义上很容易。

2025 年 3 月的化解方法（arXiv:2503.06808）：两者测量的是不同对象。成员推断问的是“样本 e 是否在 D 中？”（针对插入的金丝雀）。提取问的是“我能恢复 D 中的什么内容？”对于隐私而言，“最易提取”的样本才是关键；金丝雀低估了这一点，因为它们并非为易于提取而优化。

新的金丝雀设计。无需影子模型的基于损失的成员推断。首次对具有实际 DP 保证的真实数据上训练的 LLM 进行非平凡 DP 审计。

### DP 训练的替代方案

- **PMixED（arXiv:2403.15638）。** 推理时的私有预测。基于下一个 token 分布的专家混合；每个专家看到训练数据的一个分片；聚合时添加噪声以实现 DP。完全避免了 DP 训练。
- **DP 合成数据生成（Google Research 2024）。** 使用 DP-SGD 进行 LoRA 微调，采样合成数据，在合成数据上训练下游分类器。

两者都规避了完整 DP 训练的效用代价，但代价是威胁模型不同。

### 通过 LLM 反馈进行差分隐私逆转

2025 年新兴攻击。利用 DP 训练模型的置信度分数作为预言机来重新识别个体。即使输出不泄露，置信度分布也可能泄露。

防御措施：不暴露置信度，或在暴露前对其进行截断或量化。这是除了 (ε, δ)-DP 训练之外的额外要求。

## 使用它

`code/main.py` 在一个玩具二分类数据集上模拟 DP-SGD。你可以调整噪声乘数 σ 和裁剪范数 C，并跟踪 (ε, δ) 预算和准确率代价。一个“金丝雀攻击”会插入一个独特的训练样本，并测量在 DP 前后是否能通过对数损失测试检测到它。

## 关键术语

| 术语 | 人们怎么说 | 实际含义 |
|------|-----------------|------------------------|
| DP | “(ε, δ)-差分隐私” | 形式化隐私：相邻数据集变化下输出分布接近 |
| DP-SGD | “注入噪声的随机梯度下降” | 梯度裁剪加高斯噪声添加；标准 DP 训练 |
| LoRA + DP-SGD | “高效私有微调” | 在低秩适配器上应用 DP-SGD；2025 年标准配置 |
| MIA | “成员推断” | 判断样本是否在训练数据中的攻击 |
| Canary | “插入的水印样本” | 用于测量 DP 泄露的唯一训练样本 |
| PMixED | “私有推理混合” | 通过基于下一个 token 分布的专家混合实现推理时 DP |
| DP Reversal | “置信度泄露攻击” | 利用模型置信度作为预言机进行重新识别的攻击 |
