# 智能体的共识与拜占庭容错

> 经典的分布式系统 BFT 遇上随机的大语言模型。2025–2026 年出现了三个研究方向：**CP-WBFT** (arXiv:2511.10400) 为每个投票附加置信度探测作为权重；**DecentLLMs** (arXiv:2507.14928) 采用无领导模式，并行工作节点提议、几何中位数聚合；**WBFT** (arXiv:2505.05103) 将加权投票与层次结构聚类相结合，将节点分为核心层与边缘层。“Can AI Agents Agree?” (arXiv:2603.01213) 的诚实经验结果是：即使是标量一致在今天也很脆弱——单个欺骗性智能体就能破坏一个智能体混合系统。BFT 是必要的，但还不够。本课程构建一个最小 BFT 协议，注入三种智能体特有的攻击（拜占庭谎言、谄媚从众、相关错误单一文化），并测量每种共识变体如何应对。

**类型：** 学习 + 构建  
**语言：** Python（标准库）  
**前置条件：** 阶段 16 · 07（心智社会与辩论），阶段 16 · 13（共享内存）  
**时间：** 约 75 分钟

## 问题

你有 N 个 LLM 智能体，每个产生一个答案。它们意见不一。多数投票选错了，因为两个智能体是相关的（相同的基础模型、相同的训练数据、相同的失败模式）。第三个智能体恰好在某个新颖的方式上错了——因此多数是虚假多数。

现在加入一个欺骗性智能体：它故意撒谎。或者一个谄媚的智能体：它同意最后说话的那个。在经典 BFT 中，假设拜占庭节点占 `f < n/3` 份且行为任意。2026 年的现实是 LLM 节点即使在诚实时也是随机的，模型间相关，并且彼此的输出相互影响。你不能将它们视为独立的伯努利投票者。

经典 BFT（PBFT，1999）不是错误的——它是不完整的。它处理任意比特翻转。它不处理“三个诚实智能体因为共享训练数据而共享同一个幻觉”。本课程从 PBFT 的基础出发，并在其上叠加三个 2025–2026 的适配。

## 概念

### 经典 BFT 提供什么

实用拜占庭容错（Castro & Liskov，OSDI 1999）容忍 `f < n/3` 个拜占庭节点。该协议有三个阶段（预准备、准备、提交）和两个原语（签名消息、法定人数证书）。在 `n >= 3f + 1` 个诚实或恶意节点之间达成对一个值的共识。

保证是强的，但假设：

1. **独立故障。** 拜占庭节点不协调。
2. **诚实节点真正诚实。** 诚实输出的正确性不成问题；协议仅对齐分歧。
3. **问题有一个真值答案。** 对一个错误事实达成共识仍然是共识。

LLM 智能体违反了所有三点。两个运行相同基础模型的智能体共享故障。一个“诚实”的 LLM 仍然会幻觉。在模糊问题上，“真相”是智能体决定的——没有外部预言机。

### 三种 LLM 特有的攻击

**拜占庭谎言。** 一个智能体故意输出错误答案。如果 `f < n/3`，经典 BFT 可以处理。

**谄媚从众。** 一个智能体在投票前读取其他智能体的答案，并同意最后说话的那个。不是恶意的，但与最强声音相关。经典 BFT 无法阻止，因为该智能体通过所有签名检查。

**相关错误单一文化。** 三个智能体共享一个基础模型。它们幻觉出同一个错误答案。多数是错误的。经典 BFT 没有帮助，因为所有三个“诚实”地同意。

### 2025–2026 的回应

**CP-WBFT** (arXiv:2511.10400) —— 置信度探测加权 BFT。每个投票者为其答案附加一个置信度探测（自我报告的概率，或一个单独校准模型的预测）。投票权重随置信度缩放。报告在完全图上 BFT 改进 +85.71%。缓解：谄媚从众（顺从的智能体在其自愿立场上往往置信度较低）。

**DecentLLMs** (arXiv:2507.14928) —— 无领导。工作者智能体并行提议，评估者智能体评分提议，最终答案是得分提议的几何中位数。当 `f < n/2` 时鲁棒。缓解：拜占庭谎言和相关错误（几何中位数对异常值鲁棒，并向密集簇拉近，而不是模型偏置的平均）。

**WBFT** (arXiv:2505.05103) —— 加权 BFT 与层次结构聚类。投票权重由响应质量加上从历史学习的信任分数分配。将智能体聚类为核心和边缘；核心智能体首先必须达成共识，边缘智能体跟随。缓解：可扩展性（核心共识小且快）以及部分缓解单一文化（核心可以为了多样性而选择）。

### 经验：“Can AI Agents Agree?” (arXiv:2603.01213)

该论文测量了多个前沿模型在标量一致性（LLM 智能体对一个数值达成一致）上的表现。发现令人不安：

- 即使没有对手，LLM 智能体在许多基准上的标量问题分歧率超过 30%。
- 单个采用欺骗人格的智能体可以将智能体混合共识拉离诚实基线 40+ 个百分点。
- 分歧率与模型多样性相关——异构集成的分歧比同质的多（好：不相关错误），但漂移也更慢（坏：达成一致的时间更长）。

要点：BFT 给你对齐输出的机制，但它不告诉你对齐的输出是否正确。结合验证（阶段 16 · 08 角色专门化）、多样性（阶段 16 · 15 辩论变体）和评估智能体（阶段 16 · 24 基准）。

### 核心协议，精简版

一个用于 LLM 智能体的最小 BFT 轮次：

```
1. task arrives; each agent i produces answer a_i
2. each agent attaches confidence probe c_i in [0, 1]
3. aggregator collects (a_i, c_i) from all n agents
4. aggregator groups by semantic cluster (equivalent answers)
5. aggregator computes weight for each cluster C:
     w(C) = sum_{i in C} c_i
6. winner = cluster with max weight, if max > threshold * sum(c_i)
   else: retry or escalate
7. minority clusters logged with provenance for post-hoc audit
```

语义聚类步骤是 LLM 特有的变化。两个答案“研究报告为 4.2%”和“提升了 4.2%”属于同一个簇。朴素的字符串相等检查会遗漏。在生产中，使用便宜的嵌入模型或显式规范化。

### 阈值调优

`threshold` 参数决定何时接受以及何时重试。太低：你接受弱多数。太高：你永远不会接受。经验范围：对于 `n=5-7` 个智能体为 0.5–0.67，对于更小的 `n` 更高。低于阈值时，将问题升级给人类或不同的智能体集成。

### 共识不能帮助的地方

- **模糊问题。** 如果问题没有真值，共识是一种意见。请如是称呼。
- **复合问题。** “编写代码并解释它”——两个答案。分别对每个投票。
- **对抗性多轮。** 如果智能体可以观察之前的轮次并模仿（Du 2023 辩论），它们会开始相互同意，不管真相如何。限制轮次（通常 2–3 轮）。

## 构建它

`code/main.py` 实现了：

- `AgentVoter` —— 一个脚本策略，包含（答案，置信度）。
- `MajorityVote` —— 经典多数法。
- `CPWBFT` —— 基于置信度加权的投票，带语义聚类。
- `DecentLLMs` —— 在得分提议上进行几何中位数聚合。
- `Scenario` —— 在三种攻击模式下运行每个聚合器。

实现的攻击模式：

1. `byzantine`：一个智能体以高置信度撒谎。
2. `sycophancy`：一个智能体复制它看到的第一个答案，并附带匹配的置信度。
3. `monoculture`：三个智能体共享一个错误答案（相关错误），置信度中等。

运行：

```
python3 code/main.py
```

预期输出：一个 (攻击, 聚合器) -> 最终答案的表格，正确答案高亮。多数法在单一文化情况下失败。CPWBFT 的置信度加权缓解了谄媚。DecentLLMs 的几何中位数在单一文化少于一半群体时向诚实簇拉近。

## 交付它

在交付任何共识机制之前：

- **至少使用上述三种模式进行攻击测试。** 你的协议应该可预测地失败，而不是静默地失败。
- **记录每一个少数簇及其来源。** 少数簇是你对相关错误的早期预警系统。
- **强制有限轮次。** 不允许“持续辩论直到达成一致”——那会奖励谄媚。
- **将一致性与正确性分离。** 共识输出传递给一个验证器；验证器独立于集成。
- **监控一致性率。** 急剧上升意味着从众偏差；急剧下降意味着模型漂移。

## 练习

1. 运行 `code/main.py`。确认多数法在单一文化攻击下失败，但 CPWBFT 在单一文化置信度低于 0.7 时部分缓解它。
2. 添加第四种攻击模式：**静默弃权** —— 一个智能体拒绝回答（“我不知道”）。每个聚合器应如何处理弃权？实现你的选择。
3. 将语义聚类从字符串规范化切换为嵌入相似度（使用任何开源嵌入模型）。谄媚攻击会发生什么？
4. 阅读 CP-WBFT (arXiv:2511.10400)。实现置信度探测校准步骤（一个单独的校准模型检查每个智能体的自我报告置信度）。测量在单一文化场景下的准确率提升。
5. 阅读“Can AI Agents Agree?” (arXiv:2603.01213)。复现一个简化标量一致性实验：三个智能体，一个标量问题，欺骗人格提示。CPWBFT 或 DecentLLMs 能捕捉到它吗？

## 关键术语

| 术语 | 人们说的 | 实际含义 |
|------|----------|----------|
| BFT | “拜占庭容错” | Castro–Liskov 1999 协议，容忍 `f < n/3` 个任意故障。 |
| 拜占庭 | “任何坏行为” | 一个节点可以撒谎、丢弃消息、静默失败——除了崩溃安全以外的任何行为。 |
| 置信度探测 | “你有多大把握？” | 自我报告或校准器预测的概率，附加在投票上。 |
| 语义聚类 | “相同答案，不同措辞” | 在计数投票前对等价答案进行分组。 |
| 几何中位数 | “鲁棒中心” | 与样本点距离之和最小的点。对异常值鲁棒，不同于均值。 |
| 单一文化 | “相同模型，相同失败” | 智能体共享训练数据或基础模型时的相关错误。 |
| 谄媚从众 | “附和响亮的声音” | 智能体的投票偏向于最先/最大声说话者。 |
| 核心/边缘 | “层次化 BFT” | WBFT 拆分：先小核心共识，边缘节点跟随。限制延迟。 |
