# 代理经济体、代币激励与声誉

> 长时间运行的自主代理（METR 的 1 至 8 小时工作曲线）需要经济主体身份。新兴的 **5 层堆栈** 为：**DePIN**（物理计算）→ **身份**（W3C DID + 声誉资本）→ **认知**（RAG + MCP）→ **结算**（账户抽象）→ **治理**（代理型 DAO）。生产级代理激励网络包括 **Bittensor**（TAO 子网奖励特定任务模型）、**Fetch.ai / ASI 联盟**（ASI-1 Mini LLM + FET 代币）和 **Gonka**（基于 Transformer 的 PoW，将计算重新分配给有生产力的人工智能任务）。学术工作：AAMAS 2025 的去中心化 LaMAS 使用 **Shapley 值信用归属** 公平奖励贡献代理；Google Research 的 "Mechanism design for large language models" 提出在单调聚合下采用第二价格支付的 **代币拍卖**。本课程将构建一个最小化代理市场，对多代理流水线应用 Shapley 值信用归属，并运行一次第二价格代币拍卖，使博弈论机制具体落地。

**类型：** 学习
**语言：** Python（标准库）
**先修课程：** 阶段 16 · 16（谈判与议价），阶段 16 · 09（并行群体网络）
**时长：** 约 75 分钟

## 问题

当代理共同创造价值但需要分别获得奖励时，多代理系统变得复杂。经典机制——均分、最后贡献者全拿——不公平或易被博弈。基于联盟的 Shapley 值奖励在构造上是公平的，但计算成本高昂。2025–2026 年的文献推动了有用的近似方法：Shapley 抽样、单调聚合拍卖以及基于已确认贡献累积的链上声誉。

除了信用归属之外，该领域已转向实际的经济代理：Bittensor TAO 奖励用于微调子网专属模型的计算资源，Fetch.ai/ASI 用 FET 代币奖励 ASI-1 Mini LLM 的使用，Gonka 将 Transformer 工作量证明重新分配给有生产力的人工智能任务。能够自主交易的代理如今已经存在；问题在于如何对齐激励。

本课程将代理经济体视为一个特定的问题族——信用归属、机制设计与声誉——并用最少的数学知识逐一构建，使这些概念深入人心。

## 概念

### 代理经济体的 5 层堆栈

1. **DePIN（物理计算）。** 出租 GPU、存储、带宽的去中心化基础设施。Bittensor 子网、Render Network、Akash。非代理专属；代理使用它。
2. **身份。** W3C 去中心化标识符（DID）为每个代理提供一个独立于任何平台的持久 ID。声誉累积在 DID 上。代理网络协议（ANP）使用 DID 作为发现层。
3. **认知。** 代理的推理循环：LLM + RAG + MCP。这正是其他阶段所构建的内容。
4. **结算。** 账户抽象（ERC-4337）让代理无需持有 ETH 即可从自己的余额中支付 Gas。代理可以为服务、彼此或计算付费。
5. **治理。** 代理型 DAO：人类 *和* 代理对协议变更进行投票的治理结构，投票权与声誉挂钩。

并非每个生产系统都使用全部五层。Bittensor 使用了 1、2、部分 3、部分 4，没有使用 5。OpenAI 代理除了 3 之外均未使用。该堆栈是一个参考地图，而非要求。

### Bittensor、Fetch.ai、Gonka——实际运行的系统

**Bittensor (TAO)。** 子网是专门的任务（语言建模、图像生成、预测）。矿工提交模型输出。验证者对它们进行排名；权益加权评分分配 TAO 奖励。每个子网有自己的评估机制。经济教训：为任务特定的输出质量付费，而不是已使用的计算资源。

**Fetch.ai / ASI 联盟。** ASI-1 Mini LLM 在 Fetch.ai 网络上运行；用户支付 FET 代币进行推理。这里代理即对等体的叙事更强：Fetch 上的代理可以调用另一个代理执行任务并用 FET 支付。

**Gonka。** Transformer 工作量证明：其“工作”是 transformer 的前向传播。矿工通过执行已知正确输出（来自训练数据）的推理任务来获得收益。这是一种有资源生产力的 PoW，而非基于哈希的 PoW。

截至 2026 年 4 月，这三个系统均已达到生产级别。收益分配方式不同。Bittensor 根据子网验证者相对评分奖励质量；Fetch 根据付费用户衡量的效用奖励；Gonka 奖励可验证的推理工作。

### Shapley 值信用归属

三个代理协作完成一项任务。输出得分为 0.8。谁贡献了什么？

Shapley 值：满足四个公理（效率、对称性、线性性、零贡献者）的唯一信用分配方案。对于代理 `i`：

```
shapley(i) = (1/N!) * sum over all orderings O of (v(S_i_O ∪ {i}) - v(S_i_O))
```

其中 `S_i_O` 是在排序 `O` 中位于 `i` 之前的代理集合。在实践中：枚举所有排列，记录每个代理在每个排列中的边际贡献，然后求平均。

对于 N=3 个代理，有 6 种排列。对于 N=10，有 360 万种——因此实践中是对排序进行抽样，而非全部枚举。

### 用于聚合的第二价格拍卖

Google Research ("Mechanism design for large language models") 提出了用于聚合 LLM 输出的第二价格代币拍卖。设置：N 个代理各自提出一个补全，每个代理对被选中有各自的私人估值。拍卖者选择估值最高的提案，并支付 *第二高* 的估值。在单调聚合下（估值取决于选择哪个提案，而非有多少提案被竞标），这是诚实的——代理会报出他们的真实估值。

为什么这对 LLM 系统很重要：你可以将补全任务外包给多个定价不同的代理；拍卖选出最佳方案并公平支付，且代理没有歪曲报价的动机。

### 声誉资本

一个与 DID 绑定的声誉分数从已确认的贡献中累积。一个简单的更新规则：

```
rep(i, t+1) = alpha * rep(i, t) + (1 - alpha) * contribution_quality(i, t)
```

其中衰减因子 `alpha` 接近 1。声誉：

- 读取成本低，可用于路由决策（“将困难任务分配给高声誉代理”）。
- 伪造成本高（随时间累积，与 DID 绑定）。
- 可被惩罚：未通过验证的贡献会扣除分数。

### AAMAS 2025 去中心化 LaMAS

LaMAS 提案（AAMAS 2025）结合了：DID 身份、Shapley 值信用归属和简单的拍卖机制。关键主张是：将信用归属步骤去中心化，使系统可审计且免受单点操纵。

### 经济学在何处失效

- **价格预言机操纵。** 如果信用函数可以被操纵，代理就会操纵它。每种机制都需要对抗性测试。
- **女巫攻击。** 一个操作者启动 N 个虚假代理来夸大自己的贡献。DID 能减缓但无法阻止这种行为；声誉的伪造成本是缓解措施。
- **验证成本。** 信用归属的公平性取决于验证者。如果验证成本低（小型 LLM），则可能被操纵；如果成本高（人工评审），则系统无法扩展。
- **监管阴影。** 代理经济体与金融监管相交织。截至 2026 年，Bittensor、Fetch 和 Gonka 在某些司法管辖区均处于法律灰色地带。

### 代理经济何时有意义

- **异构运营者的开放网络。** 没有单一团队控制所有代理。
- **可验证的输出。** 没有验证，信用归属就是猜测。
- **长时间工作流。** 一次性任务无法从声誉累积中受益。
- **代币化支付在您的司法管辖区在法律上可行。**

在封闭的公司系统中，经济学会让位于更简单的分配（经理分配工作，指标内部化）。经济学文献主要适用于开放网络。

## 投入生产

2026 年运行代理经济体：

- **从声誉开始，而不是代币。** 声誉实现成本低，且本身就有价值；代币会增加法律和经济复杂性。
- **先验证再奖励。** 未经独立验证步骤，绝不分配信用。自我报告的质量会招致女巫游戏。
- **Shapley 抽样而非精确计算。** 抽样 100–1000 个排序；精确枚举无法扩展。
- **设置衰减因子上限和声誉下限。** 无上限的衰减会清除合法贡献者；衰减过慢会奖励僵化的高声誉代理。
- **对抗性地审计机制。** 在开放网络之前进行红队测试。每种机制都有其博弈论；你想找出漏洞，而不是等待攻击者。

## 练习

1. 运行 `code/main.py`。确认 Shapley 值之和等于总价值（效率公理）。更改价值函数；Shapley 分配是否按预期方向变化？
2. 实现 Shapley *抽样*（基于 K 个排序的蒙特卡洛）。K 如何影响近似精度？对于 N=4，与精确计算进行比较。
3. 在拍卖步骤之前实现联盟形成步骤：代理可以合并成团队并作为整体竞标。哪些联盟会形成？结果是否优于个人竞标（帕累托最优）？
4. 阅读 Google Research 的机制设计博客。找出一个假设，如果被违反，会破坏诚实性。在 LLM 环境中，这种失败模式是什么样的？
5. 阅读 AAMAS 2025 去中心化 LaMAS 论文。在合成任务上对 10 个代理实现他们的 Shapley 步骤。精确计算需要多长时间？100 次抽样的近似效果如何？

## 关键术语

| 术语 | 人们怎么说 | 实际含义 |
|------|------------|----------|
| DePIN | "去中心化物理基础设施" | 代币激励的计算/存储/带宽。Bittensor、Akash、Render。 |
| DID | "去中心化标识符" | W3C 规范的便携式 ID。代理声誉绑定到 DID，而非平台。 |
| ERC-4337 | "账户抽象" | 可赞助 Gas 的合约账户，使代理支付成为可能。 |
| Shapley 值 | "公平信用归属" | 满足效率、对称性、线性性、零贡献者的唯一分配。 |
| 第二价格拍卖 | "维克里拍卖" | 诚实机制：赢家支付第二高报价。与单调聚合兼容。 |
| 声誉资本 | "累积分值" | 绑定 DID 的来自已确认贡献的分数；随时间衰减。 |
| 代理型 DAO | "代理 + 人类共同治理" | 代理投票者作为一等公民，投票权与声誉挂钩。 |
| TAO / FET / GPU credits | "代币面额" | Bittensor TAO、Fetch.ai FET、各种 DePIN 代币。 |
