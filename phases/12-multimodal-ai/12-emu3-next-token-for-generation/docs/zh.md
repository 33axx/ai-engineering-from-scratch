# Emu3：图像与视频生成的下一令牌预测

> BAAI的Emu3（Wang等人，2024年9月）是2024年本应终结扩散与自回归之争的成果。一个单一的Llama风格解码器专用Transformer，仅使用下一令牌预测目标训练，在文本 + VQ图像令牌 + 3D VQ视频令牌的统一词表上，在图像生成上击败了SDXL，在感知任务上击败了LLaVA-1.6。没有CLIP损失，没有扩散调度。推理时使用无分类器引导来提升质量，但核心训练目标是带有教师强制的下一令牌预测。发表在《Nature》上。本课程解读Emu3的论文——为什么更好的分词器加上规模就足够了——并与扩散方法进行对比。

**类型：** 学习  
**语言：** Python（标准库，3D视频分词器数学 + 自回归采样骨架）  
**前置知识：** 阶段12 · 11（Chameleon）  
**时间：** 约120分钟

## 学习目标

- 解释为什么Emu3的单损失下一令牌目标能够有效，尽管长期以来人们认为图像质量需要扩散。
- 描述3D视频分词器：时空VQ码本是什么样，为什么块跨越时间。
- 比较Emu3与Stable Diffusion XL（训练计算量、推理成本、质量上限）。
- 说出同一个Emu3模型扮演的三个角色：Emu3-Gen（图像生成）、Emu3-Chat（感知）、Emu3-Stage2（视频生成）。

## 问题所在

截至2024年的传统观点：图像生成需要扩散。论点是：离散图像令牌丢失了太多信息，无法重建细节，而且自回归采样会在数千个令牌上累积误差。Stable Diffusion、DALL-E 3、Imagen、Midjourney都使用某种形式的扩散。Chameleon（第12.11课）在小规模上部分反驳了这一点，但在质量上未能达到SDXL的水平。

Emu3正面挑战了这一论点。其主张是：更好的视觉分词器 + 足够的规模 + 下一令牌损失 = 在同一个也能做感知的模型中实现击败扩散的图像生成。

这个赌注在发表时引起了争议。两年后，开源统一生成系列（Emu3、Show-o、Janus-Pro、Transfusion）成为研究领域的默认路径；生产前沿模型似乎也使用了某种变体。

## 设计理念

### Emu3 分词器

关键成分是视觉分词器。Emu3训练了一个自定义的IBQ类分词器（逆瓶颈量化器，SBER-MoVQGAN系列），每个令牌实现8x8分辨率缩减。一个512x512的图像变成64x64 = 4096个令牌，码本大小为32768。

这比Chameleon每512x512图像使用1024个令牌（K=8192）要大，但每个令牌更便宜（更小的码本查找，更简单的编解码器）。关键指标：重建PSNR达到30.5 dB，与Stable Diffusion的连续潜在空间（32 dB）相当。

对于视频：一个3D VQ分词器将一个时空块（4x4x4像素）编码为一个整数。一个4秒片段，8 FPS，有32帧；在256x256分辨率下，4倍空间降采样和4倍时间降采样，令牌数为 (256/4) * (256/4) * (32/4) = 64 * 64 * 8 = 32,768 个令牌。

分词器质量是天花板。Emu3的贡献部分在于“我们训练了一个非常好的分词器”。

### 单损失训练

Emu3使用一个目标：在共享词表上预测下一令牌，该词表包含文本令牌、2D图像令牌和3D视频令牌。训练过程中，权重会根据模态特定因子进行乘性调整以平衡贡献，但损失函数是相同的。

在混合数据上训练：
- 图像生成：`<文本描述> <图像> image_tokens </图像>`
- 图像感知：`<图像> image_tokens </图像> <问题> text_tokens`
- 视频生成：`<文本描述> <视频> video_tokens </视频>`
- 视频感知：类似。
- 纯文本：标准NTP。

模型从数据分布中学习在何时生成图像令牌与文本令牌。生成过程源于模型在`<图像>`标签之后预测图像令牌的能力。

### 无分类器引导与温度

自回归图像生成在推理时使用无分类器引导（CFG）会变得更好。Emu3使用了它：生成两次，一次使用完整描述，一次使用空描述，用引导权重（通常3.0-7.0）混合logits。这是扩散使用的相同CFG技巧，被借用到自回归设置中。

温度很重要：太高则出现伪影，太低则模式崩塌。Emu3推荐温度：感知任务1.0，图像生成0.8。

### 三个角色，一个模型

Emu3以三个功能不同的API形式发布，但底层权重相同：

- Emu3-Gen。图像生成。输入文本，输出图像令牌。
- Emu3-Chat。VQA与描述生成。输入图像（令牌），输出文本。
- Emu3-Stage2。视频生成与视频VQA。输入文本或视频，输出文本或视频。

没有任务特定的头部。只是不同的提示模板。同一检查点。

### 基准测试

来自Emu3论文（2024年9月）：

- 图像生成：在MJHQ-30K FID上击败SDXL（5.4 vs 5.6），GenEval综合（0.54 vs 0.55——统计持平），Deep-Eval综合指标相当。
- 图像感知：在VQAv2上击败LLaVA-1.6（75.1 vs 72.4），在MMMU上大致持平。
- 视频生成：4秒片段质量在与Sora时代公开基准测试模型相比的FVD上具有竞争力。

这些数字并不总是领先——Emu3在此处让一分，在彼处得一分——但“仅需下一令牌预测”这一主张在各模态间都是可辩护的。

### 计算成本

Emu3使用7B参数模型，在大约3000亿多模态令牌上训练。GPU时数与Llama-2-7B预训练大致相当（约2000-4000 GPU年，基于A100级芯片）。像Stable Diffusion 3这样的扩散模型在相似预算下训练，但需要单独的文本编码器和更复杂的流水线。

推理时，Emu3每张图像比SDXL慢：4096个图像令牌，30 tok/s，生成一张512x512图像约需2分钟，而SDXL只需2-5秒。推测性解码和KV缓存优化缩小了差距，但并未消除。自回归图像生成计算量很大；这是目前存在的权衡。

### 为何重要

Emu3的深层贡献是概念性的。如果下一令牌预测在图像生成上能匹配扩散，那么统一模型路径（一个损失，一个骨干网络，任意模态）就是可行的。未来的模型不需要单独的文本编码器、单独的扩散调度器、单独的VAE。一个Transformer，每个模态一个分词器，加上规模。

Show-o、Janus-Pro和InternVL-U都建立或挑战了这一论点。中国实验室（BAAI、DeepSeek）在这一方向上比美国实验室（截至2025年）发表得更为积极。

## 使用它

`code/main.py` 构建了两个玩具组件：

- 一个二维 vs 三维 VQ 分词器计数计算器：给定（分辨率、块大小、片段长度、FPS），计算图像与视频的令牌数。
- 一个带有温度和无分类器引导的自回归图像令牌采样器。

CFG实现遵循Emu3的方法——用引导权重混合条件logits和无条件logits。

## 交付它

本课程生成 `outputs/skill-token-gen-cost-analyzer.md`。给定一个生成产品规格（图像或视频、目标分辨率、质量等级、延迟预算），它会计算令牌数、推理成本，并选择Emu3系列或扩散方案。

## 练习

1. Emu3在8x8缩减下，每512x512图像生成4096个令牌。计算1024x1024和2048x2048下的等效值。推理延迟会发生什么变化？
2. 阅读Emu3第3.3节关于视频分词器的内容。描述3D VQ块的形状，以及为什么是4x4x4而不是8x8x1。
3. 无分类器引导权重5.0 vs 3.0：视觉效果是什么？在`code/main.py`中追踪数学计算。
4. 计算Emu3-7B在300B令牌上的训练FLOPs，并与Stable Diffusion 3进行比较。哪个训练成本更高？
5. Emu3在FID上击败了SDXL，但在VQAv2上不如专门的VLM。解释为什么统一损失方法在不同基准上与专家模型相比显示出不同的优势。

## 关键术语

| 术语 | 人们常说的 | 实际含义 |
|------|------------|----------|
| 下一令牌预测 | "NTP" | 标准自回归损失：给定token[0..i]，预测token[i+1]；当被分词后，对任何模态都有效 |
| IBQ分词器 | "逆瓶颈量化器" | 一类VQ-VAE，具有更大的码本（32768+），比Chameleon的重建效果更好 |
| 3D VQ | "时空量化器" | 由（时间，行，列）索引的码本；一个令牌覆盖一个4x4x4像素立方体 |
| 无分类器引导 | "CFG" | 以权重gamma混合条件logits和无条件logits；在推理时提升图像质量 |
| 统一词表 | "共享令牌" | 文本、图像、视频都从同一个整数空间中抽取；模型预测接下来出现的任意模态 |
| MJHQ-30K | "图像生成基准" | 包含3万条提示的Midjourney质量基准；Emu3在此报告FID |
