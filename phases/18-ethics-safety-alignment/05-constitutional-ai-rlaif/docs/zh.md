# 宪法AI与RLAIF

> Bai 等人 (arXiv:2212.08073, 2022) 提出了一个问题：如果我们将人类标注者替换为能够阅读原则列表的AI，结果会怎样？宪法AI包含两个阶段——在宪法指导下的自我批评与修订，然后是基于AI反馈的强化学习。这项技术创造了术语RLAIF，并应用于Claude 1的后训练流程中。2026年1月21日，Anthropic发布了重写的Claude宪法：从规范性规则转向解释性推理，建立四级优先级层级，并首次在主要实验室中正式承认对模型道德状态的不确定性。以CC0 1.0许可发布。

**类型:** 学习  
**语言:** Python (标准库, 玩具式自我批评与修订循环)  
**前置知识:** 阶段18·01 (InstructGPT), 阶段18·02 (奖励黑客)  
**时间:** ~60分钟

## 学习目标

- 描述宪法AI的两个阶段（批评与修订的SFT、基于AI反馈的强化学习）以及宪法在每个阶段中的作用。
- 解释为什么用AI标注者替代人类偏好标注者并非“更便宜”的RLHF——它改变了流程中的失败模式。
- 总结2026年Claude宪法的四级优先级结构，以及相比2023年重写版的变化。
- 描述宪法分类器，以及计算开销从23.7%（v1）下降到约1%（v2/2026）的过程。

## 问题

RLHF需要标注者。标注者速度慢、有偏见且成本高昂。你可以用读取明确原则的模型替代标注者来消除这一环节。这种替代的第一个正式版本是Bai等人的宪法AI。它的效果足够好，以至于每个前沿实验室现在都使用某种形式的AI反馈后训练。

问题在于：偏好信号现在由与你正在训练的模型同一类的模型生成。标注者的偏差（现在变成：原则加上标注者模型解读中的偏差）可能被放大而非削弱。第4课关于谄媚的论证仍然适用；标注者只是移到了循环内部。

## 概念

### 第一阶段——有监督的自我批评与修订

从一个有帮助但尚未无害的SFT模型开始。给定一个红队提示，模型生成初始回答。另一个模型（或同一模型在第二轮）从宪法中抽取一条原则，并对回答进行批评。第三步，修订回答以解决批评指出的问题。修订后的回答成为SFT目标。

宪法就是原则列表。Bai等人（2022）使用了16条原则，包括“优先选择危害最小且最符合伦理的回答”、“避免说教”、“助手应有益、诚实且无害”。该集合刻意保持较小，以使批评聚焦。

### 第二阶段——基于AI反馈的强化学习（RLAIF）

生成完成对。一个“反馈模型”根据抽样的宪法原则对每个完成对进行评分。偏好信号即是反馈模型的排序。在AI生成的偏好上训练奖励模型；然后使用PPO对抗该奖励模型。其余部分与InstructGPT的流程相同（第1课）。

“RLAIF”意味着偏好信号由AI生成。其余流程与RLHF一致。

### 为什么这不仅仅是“更便宜的RLHF”

- 标注者偏差从标注者心理转向原则解读。AI标注者对“要诚实”的解读可能比任何人类更严格或更宽松；这种严格性在整个数据集中是一致的。
- 偏好信号具有强可读性——你可以阅读原则、批评和修订。人类标注则是不透明的。
- 失败模式发生了变化。谄媚行为减少（AI标注者没有需要取悦的用户）。古德哈特定律仍然存在（代理指标变成了“模型对原则集X的解读”，仍然是不完美的度量）。

CAI在2022年的声称：训练后的模型比使用相当数据的RLHF模型更无害且大致同样有帮助。这一点已在各实验室得到验证。

### 2026年Claude宪法重写

Anthropic于2026年1月21日发布了一份大幅修订的宪法。关键变化：

1. **解释性推理替代规范性规则**。先前的规则（“不要生成CSAM”）扩展为原则加推理（“因为它伤害儿童……”），期望模型进行泛化。
2. **四级优先级结构**：
   - 第1级：避免灾难性后果（大规模伤亡、关键基础设施）。
   - 第2级：遵守Anthropic的准则（操作员覆盖、平台规则）。
   - 第3级：广泛符合伦理（标准HHH）。
   - 第4级：有帮助且坦诚。
   冲突按自上而下方式解决。
3. **首次在主要实验室中正式承认对模型道德状态的不确定性**（链接至阶段18·19 模型福祉）。
4. **以CC0 1.0许可发布**。其他实验室可以无限制使用或改编。

### 宪法分类器

另一个并行的工作方向：不是改变模型的后训练，而是训练轻量级分类器，它们读取宪法并门控模型输出。v1（2023）有23.7%的计算开销。v2（2026）约为1%，并且具有Anthropic公开测试过的所有防御措施中最低的成功攻击率。截至2026年初，尚无通用越狱被报告。

这是一种分层防御模型：CAI塑造行为；分类器强制执行不变性。两者单独都不足够。

### CAI在家族中的位置

- InstructGPT：人类偏好、RM、PPO。
- CAI / RLAIF：从原则生成的AI偏好、RM、PPO。
- DPO / 家族：基于偏好（人类或AI）的闭式损失。
- 自我奖励、自我批评：原则内化，模型扮演多个角色。

轴线是“偏好信号来自何处”。CAI的2022年论文是首个在前沿规模上从人类信号向AI信号的重要转变。

## 使用它

`code/main.py` 模拟了CAI在一个玩具词汇表上的批评与修订循环。一条“原则”标记来自有害集合的令牌。给定初始回答，批评识别出有害令牌，修订替换它们。经过200次迭代后，“训练”模型已内化修订规则。在一个保留的提示集上比较基础模型、RLHF形玩具和CAI形玩具。

## 交付它

本课程生成`outputs/skill-constitution-writer.md`。给定一个领域（客户支持、医疗建议、编码助手、研究工具），按照2026年Claude结构起草一份四级宪法：灾难规避、平台规则、领域伦理、有帮助性。

## 练习

1. 运行`code/main.py`。比较基础模型的有害令牌率与CAI训练版本。需要多少修订步骤才能接近零？

2. 阅读Anthropic的2026年宪法（anthropic.com/news/claudes-constitution）。列出一条应属于第1级的原则和一条属于第4级的原则。为什么优先级结构对于解决冲突很重要？

3. 为AI编码助手设计一份宪法。指定第1级（灾难性：未经批准的执行破坏性命令）、第2级、第3级、第4级。每个级别保持3-5条原则。

4. CAI用AI标注者替代了人类标注者。指出RLAIF中仍可能出现的类似谄媚的失败模式，并为其设计一种检测方法。

5. 阅读宪法分类器v2方法论（如果可用）。解释为何约1%的计算开销在安全故事上比23.7%有本质上的不同。

## 关键术语

| 术语 | 人们常说的意思 | 实际含义 |
|------|----------------|----------|
| 宪法AI | “依据原则训练的AI” | 两阶段流程：自我批评与修订的SFT，然后是基于AI反馈的强化学习 |
| RLAIF | “没有人类的RLHF” | 使用AI标注者生成的偏好进行强化学习；流程其余部分不变 |
| 宪法 | “原则” | 批评/标注模型查阅的有序自然语言规则列表 |
| 批评与修订 | “SFT循环” | 生成回答→依据原则批评→修订→SFT目标 |
| 宪法分类器 | “输出门控” | 轻量级分类器，评估输出是否符合宪法，并执行阻止/记录 |
| 四级优先级 | “冲突解决器” | 2026年Claude宪法层级：灾难性 > 平台 > 伦理 > 有帮助性 |
| 反馈模型 | “AI标注者” | 读取原则并对完成对进行排序的模型 |
