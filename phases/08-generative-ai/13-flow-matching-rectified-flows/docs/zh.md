# 流匹配与修正流

> 扩散模型需要20-50步采样，因为它们走的是从噪声到数据的弯曲路径。流匹配（Lipman et al., 2023）和修正流（Liu et al., 2022）训练了直线路径。路径越直，步数越少，推理速度越快。Stable Diffusion 3、Flux.1 以及 AudioCraft 2 在2024年都切换到了流匹配。

**类型：** 构建
**语言：** Python
**前置知识：** 第8阶段·06（DDPM），第1阶段·微积分
**时间：** ~45分钟

## 问题所在

DDPM的反向过程是一个从 `N(0, I)` 回到数据分布的1000步随机游走。DDIM将其压缩到20-50步确定性步数。但你想要更少步数——理想情况下一步完成。障碍在于求解反向过程的ODE是刚性的；路径是弯曲的。

如果你能训练模型，使得从噪声到数据的路径是一条*直线*，那么从 `t=1` 到 `t=0` 的单个欧拉步就能工作。流匹配直接构建这一点：定义从 `x_1 ∼ N(0, I)` 到 `x_0 ∼ data` 的直线插值，训练一个向量场 `v_θ(x, t)` 来匹配其时间导数，推理时积分即可。

修正流（Liu 2022）更进一步：通过一种重流过程迭代地拉直路径，该过程产生一个逐渐接近线性的ODE。经过两次重流迭代后，一个2步采样器就能匹敌50步DDPM的质量。

## 概念

![流匹配：噪声与数据之间的直线插值](../assets/flow-matching.svg)

### 直线流

定义：

```
x_t = t · x_1 + (1 - t) · x_0,   t ∈ [0, 1]
```

其中 `x_0 ~ data`，`x_1 ~ N(0, I)`。沿着这条直线的时间导数是常数：

```
dx_t / dt = x_1 - x_0
```

定义一个神经网络向量场 `v_θ(x_t, t)` 并训练它匹配这个导数：

```
L = E_{x_0, x_1, t} || v_θ(x_t, t) - (x_1 - x_0) ||²
```

这就是**条件流匹配**损失（Lipman 2023）。训练是无需模拟的：你永远不需要展开ODE。只需采样 `(x_0, x_1, t)` 并进行回归。

### 采样

在推理时，沿着学习到的向量场*反向*积分：

```
x_{t-Δt} = x_t - Δt · v_θ(x_t, t)
```

从 `x_1 ~ N(0, I)` 开始，欧拉步下降到 `t=0`。

### 修正流（Liu 2022）

直线流是有效的，但学习到的路径*实际上并不直*——它们会弯曲，因为许多 `x_0` 可以映射到同一个 `x_1`。修正流的重流步骤：

1.  用随机配对训练流模型 v_1。
2.  通过从 `x_1` 积分 v_1 到其落脚点 `x_0`，采样 N 对 `(x_1, x_0)`。
3.  在这些配对样本上训练 v_2。因为这些配对现在是"ODE匹配"的，它们之间的直线插值真正更平坦。
4.  重复。

实际上，两次重流迭代就能达到接近线性，从而实现2-4步推理。SDXL-Turbo、SD3-Turbo、LCM 都是从流匹配模型蒸馏得到的。

### 为什么这在2024年赢得了图像领域

三个原因：

1.  **无需模拟的训练**——训练时无需展开ODE，实现简单。
2.  **更好的损失几何**——直线路径具有一致的信号噪声比，而DDPM的ε损失在计划的两端具有较差的SNR。
3.  **更快的推理**——4-8步达到SDXL-Turbo质量；1步通过一致性蒸馏。

## 流匹配 vs DDPM——精确联系

使用高斯条件路径的流匹配是*具有特定噪声计划*的扩散。选择 `x_t = α(t) x_0 + σ(t) x_1` 计划，流匹配恢复了具有 `v = α'·x_0 - σ'·x_1` 的Stratonovich重新表述的扩散。对于高斯路径，两者在代数上是等价的。

流匹配带来的新东西：目标的*清晰性*（一个简单的速度），更干净的损失，以及尝试非高斯插值的自由度。

## 动手构建

`code/main.py` 实现了在一维双峰高斯混合上的流匹配。向量场 `v_θ(x, t)` 是一个小型MLP，用直线目标训练。推理时，分别以1、2、4和20个欧拉步积分，并比较样本质量。

### 第1步：训练损失

```python
def train_step(x0, net, rng, lr):
    x1 = rng.gauss(0, 1)
    t = rng.random()
    x_t = t * x1 + (1 - t) * x0
    target = x1 - x0
    pred = net_forward(x_t, t)
    loss = (pred - target) ** 2
    # backprop + update
```

### 第2步：多步推理

```python
def sample(net, num_steps):
    x = rng.gauss(0, 1)
    for i in range(num_steps):
        t = 1.0 - i / num_steps
        dt = 1.0 / num_steps
        x -= dt * net_forward(x, t)
    return x
```

## 常见陷阱

-   **时间参数化。** 流匹配使用 `t ∈ [0, 1]`，其中 `t=0` 是数据，`t=1` 是噪声。DDPM使用 `t ∈ [0, T]`，其中 `t=0` 是数据，`t=T` 是噪声。方向相同，尺度不同。论文中经常会搞错这一点。
-   **计划选择。** 修正流的直线是"标准"的流匹配计划，但你可以使用余弦或 logit-normal t 采样（SD3就是这样做的）来获得更好的尺度覆盖。
-   **重流成本。** 为重流生成配对数据集需要对每个样本进行一次完整的推理过程。只有当你真正需要1-2步推理时才进行重流。
-   **无分类器引导仍然适用。** 只需在线性组合中将 ε 替换为 v：`v_cfg = (1+w) v_cond - w v_uncond`。

## 交付使用

保存 `outputs/skill-fm-tuner.md`。该技能接收一个扩散风格的模型规格，并将其转换为流匹配训练配置：计划选择、时间采样分布（均匀 / logit-normal）、优化器、重流计划、目标步数、评估协议。

## 练习

1.  **简单。** 运行 `code/main.py`，比较1步与20步的MSE相对于真实数据分布。
2.  **中等。** 从均匀 `t` 采样切换到 logit-normal（将采样集中在中间 `t` 值）。模型质量是否提高？
3.  **困难。** 实现一次重流迭代：通过积分第一个模型生成配对的 (x_0, x_1)，在配对上训练第二个模型，比较1步样本质量。

## 关键术语

| 术语 | 人们怎么说 | 实际含义 |
|------|-----------------|-----------------------|
| 流匹配 | "直线扩散" | 训练 `v_θ(x, t)` 沿着插值匹配 `x_1 - x_0`。 |
| 修正流 | "重流" | 迭代过程，使学习到的流变得直线。 |
| 速度场 | "v_θ" | 模型的输出——移动 `x_t` 的方向。 |
| 直线插值 | "路径" | `x_t = (1-t)·x_0 + t·x_1`；简单的目标导数。 |
| 欧拉采样器 | "一阶ODE求解器" | 最简单的积分器；路径直时效果好。 |
| Logit-normal t | "SD3采样" | 将 `t` 采样集中到梯度最强的中间值附近。 |
| 一致性蒸馏 | "一步采样器" | 训练一个学生模型将任何 `x_t` 直接映射到 `x_0`。 |
| 速度CFG | "v-CFG" | `v_cfg = (1+w) v_cond - w v_uncond`；相同的技巧，新的变量。 |

## 生产实践笔记：Flux.1-schnell 是最快的流匹配

流匹配在生产上的胜利是 Flux.1-schnell——一个流匹配的 DiT 模型，蒸馏到1-4推理步，同时保持 Flux-dev 级别的质量。Niels 的"在8GB机器上运行Flux"笔记本是参考部署配方：T5 + CLIP编码，量化 MMDiT 去噪（schnell 4步 vs dev 50步），VAE解码。成本核算：

| 变体 | 步数 | 在L4上1024²的延迟 | 总FLOPs（相对值） |
|---------|-------|------------------------|------------------------|
| Flux.1-dev（原始） | 50 | ~15秒 | 1.0× |
| Flux.1-schnell | 4 | ~1.2秒 | 0.08×（快12倍） |
| SDXL-base | 30 | ~4秒 | 0.25× |
| SDXL-Lightning 2-step | 2 | ~0.3秒 | 0.03× |

生产规则：**流匹配基模型 + 蒸馏 = 2026年快速文生图的默认方案。** 每个主要供应商都在推出这一组合：SD3-Turbo（SD3 + 流 + 蒸馏）、Flux-schnell（Flux-dev + 修正流拉直）、CogView-4-Flash。纯扩散基模型仅用于遗留检查点。
