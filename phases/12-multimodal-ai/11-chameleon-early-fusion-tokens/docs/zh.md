# 变色龙与早期融合纯令牌多模态模型

> 到目前为止，我们见过的每一个视觉语言模型都将图像和文本分开处理。视觉标记来自视觉编码器，流入投影器，然后在LLM内部与文本相遇。视觉词汇和文本词汇从不重叠。Chameleon（Meta，2024年5月）提出了一个问题：如果它们重叠会怎样？训练一个VQ-VAE，将图像转换为来自共享词汇表的离散令牌序列。现在每一个多模态文档都是一个序列——文本令牌和图像令牌交错排列，使用单一的因果损失。副作用是：模型可以生成混合模态的输出——在单次推理调用中交替生成文本和图像令牌。本课将阅读早期融合论文，并从头构建一个玩具版本。

**类型：** 构建
**语言：** Python（标准库，VQ-VAE令牌化器 + 交错解码器）
**先决条件：** 阶段 12 · 05，阶段 8（生成式AI）
**时间：** ~180分钟

## 学习目标

- 解释为什么共享词汇表 + 单一损失会改变模型的能力。
- 描述VQ-VAE如何将图像令牌化为与Transformer的下一个令牌目标兼容的离散序列。
- 列举Chameleon的训练稳定性技巧：QK-Norm、dropout放置、LayerNorm顺序。
- 比较Chameleon与BLIP-2的Q-Former方法，并描述何时选择哪一种方法最合适。

## 问题

基于适配器的VLM（LLaVA、BLIP-2、Qwen-VL）将文本和图像视为两种不同的东西。一个文本令牌经过 `embed(text_token)`；一张图像经过 `visual_encoder(image) → projector → ... pseudo_tokens`。模型有两个输入路径，在中间某处合并。

三个后果：

1. LLM只能消费图像，而不能生成它们。输出仅限于文本。
2. 混合模态文档（例如文章中交替出现的段落和图像）处理起来很尴尬——你只能在模型外部解析多模态输入，或者串联生成过程。
3. 分布不匹配。视觉令牌和文本令牌位于隐藏空间的不同区域，造成微妙的对齐问题。

Chameleon拒绝了这一前提：图像只是来自共享词汇表的离散令牌序列。在交错文档上训练模型，一个损失，一个因果解码器，你就免费获得了混合模态生成。

## 概念

### VQ-VAE作为图像令牌化器

令牌化器是一个向量量化的变分自编码器。架构如下：

- 编码器：CNN + ViT，将图像映射到一个空间特征图，例如32x32特征，维度256。
- 码本：一个包含K个向量的学习词汇表（Chameleon使用8192个），维度也是256。
- 量化：对于每个空间特征，按L2距离查找最近的码本条目。将连续特征替换为整数索引。
- 解码器：CNN，将量化后的特征映射回像素。

训练：VAE重建损失 + 承诺损失 + 码本损失。码本索引构成了图像的离散字母表。

对于Chameleon：一张图像变成32*32 = 1024个令牌，来自词汇表8192。与文本令牌（来自LLM的BPE词汇表，例如32000）拼接。最终词汇表大小：40192。Transformer看到一个序列，一个损失。

### 共享词汇表

Chameleon的词汇表结合了文本令牌、图像令牌和模态分隔符。每个令牌有一个唯一的ID。输入嵌入层将每个ID映射到一个D维隐藏向量。输出投影将隐藏向量映射回逻辑值。Softmax选择下一个令牌，无论模态如何。

分隔符很重要：`<image>` 和 `</image>` 标签将图像令牌序列括起来。在生成时，如果模型生成 `<image>`，下游软件就知道接下来的1024个令牌是VQ索引，需发送给解码器进行像素渲染。

### 混合模态生成

推理是共享词汇表上的下一个令牌预测。示例提示：“画一只猫并描述它。”Chameleon生成：

```
<image> 4821 1029 2891 ... (1024 image tokens) </image>
The cat is orange, sitting on a windowsill...
```

模型自主决定顺序——它可能先生成图像再生成文本，或文本再图像，或交错生成。同一个解码器，同一个损失。

与仅文本输出的适配器VLM相比，Chameleon重新开启了模型输出模态的问题。

### 训练稳定性——QK-Norm、dropout、LayerNorm顺序

早期融合训练在大规模下不稳定。Chameleon论文记录了三个技巧：

- QK-Norm：在注意力内部，点积之前对Query和Key投影应用LayerNorm。防止深度下logit幅度爆炸。被多个2024年之后的大型模型使用。
- Dropout放置：在每个残差加之后应用dropout，而不仅仅是在注意力和MLP之后。当来自图像令牌的梯度可能占主导时，需要更多正则化。
- LayerNorm顺序：残差分支上的Pre-LN（标准做法），加上最后一个块的跳跃连接上的额外LN。稳定最后一层的梯度流动。

没有这些技巧，34B参数的Chameleon训练在多个检查点发散。有了它们，就能收敛。训练方案与架构本身一样重要。

### 令牌化器的重建上限

VQ-VAE是有损的。当码本大小为8192，每个512x512图像使用1024个令牌时，重建PSNR上限约为26-28 dB。这足以产生可识别的图像生成，但明显差于连续空间扩散（Stable Diffusion 3达到32+ dB）。

令牌化器是瓶颈。更好的令牌化器（MAGVIT-v2、IBQ、SBER-MoVQGAN）提高了上限。Emu3（第12.12课）仅通过更好的令牌化器就实现了SDXL级别的生成质量。

### Chameleon vs BLIP-2 / LLaVA

Chameleon（早期融合、共享词汇表）：
- 一个损失，一个解码器。
- 生成混合模态输出。
- 令牌化器是质量上限。
- 代价高昂：每次生成的图像都需要VQ-VAE解码器在推理路径上运行。

BLIP-2 / LLaVA（后期融合、独立塔）：
- 仅视觉输入，文本输出。
- 复用预训练LLM。
- 理解任务没有令牌化器瓶颈。
- 成本低廉：单次前向传递。

根据任务选择。如果需要图像生成，选择Chameleon家族。如果只需要理解，适配器-VLM更简单，并能更多地复用预训练计算。

### Fuyu和AnyGPT

Fuyu（Adept，2023）是一种相关方法：跳过独立的视觉编码器，直接将原始图像块送入LLM的输入投影，就好像它们是令牌一样，没有令牌化器。比Chameleon更简单，但失去了共享词汇表输出生成的能力。

AnyGPT（Zhan等人，2024）将Chameleon扩展到四种模态：文本、图像、语音、音乐。对每种模态使用相同的VQ-VAE技巧，共享Transformer。任意到任意生成。在第12.16课中有更多介绍。

## 使用它

`code/main.py` 构建了一个玩具端到端早期融合模型：

- 一个微型的类VQ-VAE量化器，将8x8块映射到码本索引（K=16）。
- 一个共享词汇表：（文本ID 0..31）+（图像ID 32..47）+（分隔符48、49）。
- 一个玩具自回归解码器（二元语法表），在合成标题+图像令牌序列上训练。
- 采样循环，在给定提示后生成交替的文本+图像令牌。

代码特意保持Transformer很小（二元语法），以便你可以从头到尾追踪信号流。

## 练习

1. Chameleon使用K=8192码本条目，每个512x512图像使用1024个令牌。估计相对于24位RGB图像的压缩比。这是有损的吗？损失有多大？

2. 一张4K图像（3840x2160）在相同VQ-VAE密度下会产生多少个图像令牌？Chameleon风格的模型能否在一次推理调用中生成4K图像？首先突破的是哪一项——上下文、令牌化器质量还是KV缓存？

3. 用纯Python实现QK-Norm。给定一个64维的Query和Key，展示LayerNorm前后的点积结果。为什么深度下幅度控制很重要？

4. 阅读Chameleon第2.3节关于训练稳定性的内容。描述论文在34B规模下没有QK-Norm时观察到的具体失败模式。“范数爆炸”的标志是什么？

5. 扩展玩具解码器，使其在只给文本提示时生成混合模态响应。在训练数据分布为60%文本优先 / 40%图像优先的情况下，测量模型选择图像优先与文本优先的频率。

## 关键术语

| 术语 | 人们说的 | 实际含义 |
|------|---------|----------|
| Early fusion | “统一令牌” | 图像从一开始就被转换为与Transformer共享词汇表的离散令牌 |
| VQ-VAE | “图像令牌化器” | CNN + ViT + 码本，将图像映射到Transformer可以预测的整数索引 |
| Shared vocabulary | “一个字典” | 一个单一的令牌ID空间，覆盖文本、图像和模态分隔符 |
| QK-Norm | “注意力稳定器” | 在Query和Key的点积之前对其应用LayerNorm，防止范数爆炸 |
| Mixed-modality generation | “文本+图像输出” | 推理时自主产生交错文本和图像令牌的生成方式 |
| Codebook size | “K个条目” | VQ-VAE可以量化到的离散向量数量；在压缩与保真度之间权衡 |
| Tokenizer ceiling | “重建限制” | 解码VQ令牌所能达到的最佳PSNR；限制了模型的图像质量 |
