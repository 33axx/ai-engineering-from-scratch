# MIO 与任意到任意流式多模态模型

> GPT-4o 发布了一个大多数开放模型无法复制的产品：一个能够听到语音、看到视频并实时回应的智能体。到2024年底，开放生态的答案便是 MIO（Wang 等人，2024年9月）。MIO 将文本、图像、语音和音乐进行标记化，用一个因果变换器处理交错序列，并生成任意模态到任意模态的输出。AnyGPT（Zhan 等人，2024年2月）是概念验证；MIO 是规模放大版；Unified-IO 2（Allen AI，2023年12月）则是加入了视觉+动作基础的表亲。本课程将解读任意到任意模式——四个分词器、一个变换器、支持流式解码。

**类型：** 学习
**语言：** Python（标准库，四模态标记分配器 + 流式解码循环）
**前置知识：** 阶段12 · 11（Chameleon），阶段6（语音与音频）
**时间：** ~120分钟

## 学习目标

- 设计一个共享词汇表，能容纳文本、图像、语音和音乐标记且无冲突。
- 比较 SEED-Tokenizer（图像）和 SpeechTokenizer residual-VQ（语音）在压缩与重建质量上的权衡。
- 解释构建任意到任意生成能力的四阶段训练课程。
- 列举三种开放的任意到任意方案及其主要权衡：MIO、AnyGPT、Unified-IO 2。

## 问题

统一的多模态模型易于宣称，但规模化构建却困难重重。直到2024年，大多数“任意到任意”系统都是流水线式的：视觉模型 → 文本表示 → 语音模型 → 音频。每一跳都会丢失信息、增加延迟并使训练复杂化。GPT-4o 的演示视频展示了一种亚秒级响应的单模型替代方案；开放系统则落后数月。

工程挑战：

- 必须为每种模态准备好分词器，以足够无损的方式进行压缩以便重建，并能以变换器可消耗的速率产生标记。
- 单个词汇表必须为文本（32k+）、图像（16k+）、语音（4k+）、音乐（8k+）分配空间。至少四万以上的条目。
- 训练数据必须涵盖每一种输入-输出对（文本→图像、图像→语音、语音→图像等），否则模型必须能够组合。
- 推理时必须足够快地流式输出标记，以满足对话级延迟（<500ms 首音频字节时间）。

## 概念

### 四种模态的四个分词器

MIO 的分词器栈：

- 文本：标准 BPE，词汇量约32000。
- 图像：SEED-Tokenizer（2023年）—— 量化 VAE，离散码本，4096个条目，每张图像32x32个标记。
- 语音：SpeechTokenizer residual-VQ（2023年）—— 将16kHz波形编码为8个分层码本；第一层是粗糙内容，后续层添加韵律和说话人身份。
- 音乐：类似的 residual-VQ（Meta 的 MusicGen / Encodec 系列），4-8个码本。

每种模态产生整数标记。这些标记在共享词汇表中获得不相交的 ID 范围：

```
text:   0..31999
image:  32000..36095  (4096 image tokens)
speech: 36096..40191  (4096 speech base tokens, plus residual layers)
music:  40192..48383  (8192 music tokens)
sep:    48384..48390  (<image>, <speech>, <music>, </...>, etc.)
```

总计：约48k词汇量。输入嵌入和输出投影覆盖全部。

### 流式解码

语音生成使用 residual-VQ。变换器预测基础（第0层）语音标记；并行解码的残差量化器预测后续各层。每个第0层标记大约对应16kHz下的50ms音频。

流式模式：

1. 用户对着麦克风讲话；实时音频分词器每50ms发出语音标记。
2. MIO 在标记到达时消费它们（提示预填充 + 增量前向传播）。
3. 输出标记在生成时流式发出；并行语音解码器将它们转换为音频样本，延迟约50-150ms。
4. 首音频字节时间：MIO 论文中约300-500ms，接近 GPT-4o 的约250ms。

Mini-Omni（arXiv:2408.16725）、GLM-4-Voice（arXiv:2412.02612）和 Moshi（arXiv:2410.00037）是互补的流式语音-语言模型设计。特别是 Moshi 在单 GPU 上实现了160ms的往返时间。

### 四阶段训练课程

MIO 的训练课程：

1. 第一阶段——对齐。大规模模态对语料：文本-图像、文本-语音、文本-音乐。每对使用自己的标记词汇段。训练共享词汇表。
2. 第二阶段——交错。多模态交错文档（带图像和视频的博客、带转录的播客等）。训练跨模态上下文。
3. 第三阶段——语音增强。额外的音频数据，在不丢失文本能力的前提下提升语音质量。
4. 第四阶段——SFT。跨模态的指令微调：VQA、描述、解说、语音到语音对话。

缺少某个阶段会削弱特定能力：跳过第二阶段则模型丢失跨模态上下文；跳过第三阶段则语音质量差。

### 视觉思维链

MIO 引入了视觉思维链：模型将中间图像标记作为推理步骤发出。对于“猫在爬树吗？”这样的问题，模型：

1. 发出 `<image>` 标记，渲染场景（来自输入图像或草图）。
2. 发出分析草图文本。
3. 发出最终答案。

渲染的中间图像充当暂存器。在空间推理任务上指标有所提升。这一思想与文本推理的思维链类似。

### 任意到任意领域的竞争者

- AnyGPT（arXiv:2402.12226）：4种模态（文本、图像、语音、音乐），设计类似。
- Unified-IO 2（arXiv:2312.17172）：添加了视觉动作输出、深度、法线。任务多样性更高，规模更小。
- NExT-GPT（arXiv:2309.05519）：LLM + 特定模态扩散解码器。并非单模型方法。
- CoDi（arXiv:2305.11846）：可组合扩散；通过共享潜在表示实现任意到任意。

MIO 是最接近纯标记任意到任意的方法。AnyGPT 是其概念前身。

### 延迟预算

对于对话产品，每个组件的延迟都很重要：

- 麦克风到音频标记：~50ms。
- 预填充（音频标记 + 历史）：8B模型上约100ms。
- 第一个输出标记：~50ms。
- 并行 residual-VQ + 语音解码器：~100-150ms。

总首音频字节时间：最少约300ms。GPT-4o 声称约250ms。Moshi 声称160ms。根据公开基准，MIO/AnyGPT 在400-600ms范围内。

### 为什么任意到任意仍然困难

即使到2026年，开放的任意到任意模型在两个方面仍然落后于封闭模型：

- 语音质量。residual-VQ 分词器是有损的；对话语音听起来比 ElevenLabs 级的声音更机械。
- 跨模态推理。要求模型“唱出你看到的”比纯视觉任务更常失败。

这些都是开放研究问题。Qwen3-Omni（课程12.20）是2025年最先进的开源尝试。

## 使用它

`code/main.py`：

- 定义四种模态的词汇分配并打印。
- 将多模态输入列表（文本、图像、音频片段、音乐）路由到分词器路由器。
- 模拟文本到语音响应的流式解码，并计算延迟。
- 根据编码器、预填充和解码器延迟计算预期的首音频字节时间。

## 练习

1. 你的产品接收语音输入并返回语音输出。端到端延迟预算目标是多少？列出消耗时间的组件。

2. SpeechTokenizer residual-VQ 使用8个码本。请论证为什么必须并行解码残差级别（而非顺序解码），以及它带来了多少延迟节省。

3. 你的词汇表有32k文本 + 4k图像 + 4k语音。加上8k音乐和约10个分隔符。在隐藏维度4096下，嵌入矩阵的参数开销是多少？

4. 视觉思维链发出一个中间图像。哪些类型的问题受益？哪些类型会因额外标记而受损？

5. 阅读 Moshi（arXiv:2410.00037）。描述其“内心独白”技术，并与 MIO 的视觉思维链进行比较。

## 关键术语

| 术语 | 人们如何说 | 实际含义 |
|------|-------------|----------|
| 任意到任意 | “多模态输入/输出” | 一个单模型，接受并生成文本、图像、语音和音乐，任意方向 |
| 残差向量量化（Residual-VQ） | “语音分词器栈” | 多层码本分词，每一层增加信息；基础层是内容，后续层是韵律 |
| SEED-Tokenizer | “图像编码” | 离散图像分词器，码本大小为4096，用于 MIO |
| 视觉思维链 | “视觉暂存器” | 模型在最终答案前生成一个中间图像作为推理步骤 |
| 首音频字节时间 | “TTFAB” | 从用户语音到第一个音频输出的延迟；<500ms 才能获得对话体验 |
| 四阶段训练课程 | “训练配方” | 对齐 → 交错 → 语音增强 → SFT，按此顺序 |
