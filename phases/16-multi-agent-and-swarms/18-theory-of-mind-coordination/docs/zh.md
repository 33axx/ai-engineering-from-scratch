# 心智理论与涌现协调

> Li 等人（arXiv:2310.10701）的研究表明，LLM 智能体在合作文本游戏中展现出**涌现的高阶心智理论**（Theory of Mind, ToM）——即推理另一个智能体关于第三个智能体信念的看法——但由于上下文管理和幻觉问题，在长周期规划中表现不佳。Riedl（arXiv:2510.05174）在群体规模上测量了高阶协同效应，发现**只有** ToM 提示条件会产生身份相关的分化和目标导向的互补性；容量较低的 LLM 仅表现出虚假的涌现现象。也就是说，协调涌现是提示条件依赖和模型依赖的，并非自由产生。本课将实现一个最小化的 ToM 感知智能体，分别在有无 ToM 提示的情况下运行一项合作任务，并依据 Riedl 2025 协议测量协调性的差异。

**类型：** 学习 + 构建
**语言：** Python（标准库）
**先修课程：** 阶段 16 · 07（思维社会与辩论），阶段 16 · 17（生成式智能体）
**时长：** 约 75 分钟

## 问题

多智能体协调通常看起来很神奇：智能体分工协作、相互预判、避免冗余。通常这种“涌现”是提示工程（prompt engineering）的产物——有人告诉智能体要“协调”。去掉提示，协调也随之消失。

Riedl 2025 年的发现更为严格：在受控条件下，只有当智能体被提示去推理**其他智能体的心智**（ToM）时，协调才会出现。没有 ToM 提示，即使是强大的模型，其协调模式也无法通过统计检验。这对生产系统至关重要：团队发布的“多智能体协调”功能实际上是提示依赖且脆弱的。

本课将 ToM 视为一种特定能力（推理关于信念的信念），构建一个最小化的 ToM 感知智能体，并衡量真实的协调与提示伪装之间的区别。

## 概念

### ToM 的含义

发展心理学：3 岁儿童认为所有人的内心世界都与自己相同。5 岁儿童理解他人拥有不同的信念。7 岁儿童能够推理关于信念的信念（“她认为我认为球在杯子下面”）。这分别是零阶、一阶和二阶 ToM。

对于 LLM 智能体，ToM 的阶次对应如下：

- **零阶：** 没有关于他人的模型。智能体仅基于自身观察行动。
- **一阶：** 智能体拥有每个其他智能体信念的模型。“爱丽丝相信 X。”
- **二阶：** 智能体建模递归信念。“爱丽丝相信鲍勃相信 X。”

Li 等人 2023 年的研究发现，在合作游戏中，LLM 智能体展现出一阶和二阶 ToM，但在长周期和不可靠通信下会退化。

### Sally-Anne 测试简介

1985 年的错误信念测试：莎莉把弹珠放在篮子 A 中，然后离开。安妮把弹珠移到篮子 B。莎莉回来时会去哪里找？拥有⼀阶 ToM 的儿童会说篮子 A（莎莉的信念与现实不同）。没有 ToM 的儿童会说篮子 B。

GPT-4 时代的 LLM 在直白陈述的 Sally-Anne 风格测试中能够通过。但当叙述较长、场景多次变化或问题表述间接时，它们会失败。这就是 2026 年生产级 LLM 中 ToM 的实际状态。

### Riedl 的协调度量

Riedl（arXiv:2510.05174）构建了一个群体规模的测试：N 个智能体，一个合作目标，可变提示条件。测量：

1. **身份相关的分化。** 智能体是否会随时间形成稳定的角色区分？
2. **目标导向的互补性。** 智能体的行动是否互补（不同子任务）而非重复？
3. **高阶协同。** 一种统计度量，用于判断群体是否达到了任何子集都无法达到的效果。

结果：只有在 ToM 提示条件下，这三项指标才能产生高于基线的信号。没有 ToM 提示，中等容量模型的指标接近随机水平。大型模型在无明确 ToM 提示时也表现出一些协调，但效果小于有明确提示的情况。

### 协调假象

没有统计控制时，演示中的“涌现协调”通常反映：

- 提示工程中内嵌了协调（系统提示要求“一起工作”）。
- 观察者偏差（我们看到了期望的模式）。
- 事后选择成功的运行结果。

宣传“涌现协调”但没有可测量信号的生产系统应被视为营销话术。在确认之前先测量。

### 最小化的 ToM 感知智能体

结构：

```
class ToMAgent:
    def __init__(self, agent_id, to_order=1):
        self.id = agent_id
        self.to_order = to_order  # 0, 1, 或 2
        self.beliefs = {}  # 关于世界的信念
        self.other_models = {}  # 对其他智能体信念的模型
        # 一阶：other_models[other_id] = {belief_key: value}
        # 二阶：other_models[other_id] = {belief_key: value, 'other_model': {sub_beliefs}}
```

`other_models` 属性就是 ToM 状态。一阶 ToM 只保留一层。二阶 ToM 增加 `other_models[i][other_models_of_j]`——我认为智能体 i 认为智能体 j 相信什么。

### 为什么长周期会带来损害

Li 等人的研究发现：上下文限制导致智能体忘记哪个信念属于谁。幻觉给其他智能体的模型添加了错误信念。两者都会产生“我以为他以为 X”的错误，并随时间累积。

论文及 2024–2026 年后续研究中提到的缓解措施：

- **在提示中明确 ToM 状态。** 结构化格式：`{agent_id: belief_list}`。强制检索以保持身份-信念绑定。
- **更短的推理链。** 每轮更新 ToM 的次数更少，减少累积幻觉。
- **外部 ToM 存储。** 将模型维护在 LLM 上下文之外；每轮只注入相关部分。

### ToM 在生产中的失败场景

- **对抗性场景。** 具有良好 ToM 的智能体更容易被操控（你可以建模它们对你建模的方式，然后加以利用）。
- **异质团队。** 当模型不同时，针对某个对手有效的 ToM 模型无法推广。
- **依赖于真实情况的任务。** ToM 是关于信念的；如果正确性依赖于事实，那么 ToM 可能会分散注意力。

### 你能实际测量的协调

三个实用信号表明团队的协调是真实的而非提示伪装：

1. **随时间呈现的互补性。** 在多轮任务中，智能体的行动是否覆盖了不重叠的子任务？
2. **预判。** 智能体 A 在轮次 T+1 的行动是否依赖于对智能体 B 在轮次 T+2 行动的预测，并且该预测后来被证实正确？
3. **纠正。** 当 A 在轮次 T 误读了 B 的信念时，A 是否在轮次 T+2 之前纠正？

这些都可以在记录日志的多智能体系统中测量。它们是“协调”叙事的具体版本。

## 构建它

`code/main.py` 实现了：

- `ToMAgent` —— 跟踪自身信念以及每个其他智能体的信念模型。
- 一个合作任务：三个智能体必须从三个盒子中收集三个代币；每个盒子只能容纳一个代币。智能体之间不能通信；它们通过观察彼此的行为来推断意图。
- 两种配置：`zeroth_order`（无 ToM）和 `first_order`（带一级信念模型的 ToM）。
- 在 200 个随机试验中进行测量：完成率、重复率（两个智能体瞄准同一个盒子）、平均完成轮数。

运行：

```
python code/main.py
```

预期输出：零阶智能体的重复率约为 35%，在 10 轮内完成约 60% 的试验。一阶 ToM 智能体的重复率约为 5%，完成率约为 95%。这个差异就是可测量的协调效应。

`outputs/skill-tom-auditor.md` 是一个技能文件，用于审计多智能体系统声称的“涌现协调”。它检查提示伪装、相对于控制组的统计显著性以及测量的互补性。

## 交付它

协调声明检查清单：

- **控制条件。** 系统的版本不带协调提示。测量两种情况。
- **统计检验。** 系统与控制组之间的差异在您的指标上是否显著（`p < 0.05`）？
- **互补性度量。** 行动随时间的不重叠程度，而不仅仅是最终成功。
- **失败案例日志。** 当智能体协调失败时，ToM 状态看起来如何？
- **模型容量披露。** 如果效果在较小模型上消失，请说明。

## 练习

1. 运行 `code/main.py`。确认一阶 ToM 将重复率降低了约 7 倍。当扩展到 5 个智能体和 5 个盒子时，差距是否依然存在？
2. 实现二阶 ToM（智能体 A 建模 B 关于 C 的信念）。它是否优于一阶？在哪些任务上更好？
3. 在 ToM 状态中注入**幻觉**：每轮随机翻转一个信念。这会在多大程度上降低一阶性能？
4. 阅读 Li 等人（arXiv:2310.10701）。复现“长周期退化”的发现：当轮数从 10 增加到 30 时，您的一阶 ToM 性能如何变化？
5. 阅读 Riedl 2025（arXiv:2510.05174）。在您的仿真日志上实现高阶协同统计量。在没有 ToM 提示条件的情况下，该效应是否存在？

## 关键术语

| 术语 | 人们说的意思 | 实际含义 |
|------|--------------|----------|
| 心智理论 | “理解他人的心智” | 建模其他智能体信念的能力。按阶次分级（0, 1, 2+）。 |
| Sally-Anne 测试 | “错误信念测试” | 1985 年发展心理学测试；LLM 能通过直白版本，但在复杂版本中失败。 |
| 一阶 ToM | “A 相信 X” | 对他人关于事实信念的建模。 |
| 二阶 ToM | “A 相信 B 相信 X” | 递归建模深度一层。 |
| 身份相关的分化 | “随时间稳定的角色” | Riedl 的度量：角色持续存在而非随机变化。 |
| 目标导向的互补性 | “不重叠的行动” | 智能体针对不同子任务，而非相同子任务。 |
| 高阶协同 | “群体超越任何子集” | Riedl 用于衡量真实协调的统计量。 |
| 协调假象 | “看起来协调” | 提示伪装出的协调外观，但没有可测量信号。 |
