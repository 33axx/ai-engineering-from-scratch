# Embodied VLAs: RT-2, OpenVLA, π0, GR00T

> 模型首次从网站读取食谱并在厨房机器人中执行，是RT-2（Google DeepMind，2023年7月）。RT-2将动作离散化为文本token，在网页数据加机器人动作数据上联合微调VLM，并证明了大规模网页视觉语言知识可迁移到机器人控制。OpenVLA（2024年6月）发布了开源的7B参考模型。Physical Intelligence的π0系列（2024-2025年）增添了流匹配动作专家。NVIDIA的GR00T N1（2025年3月）为大规模人形机器人提供了双系统（System 1 / System 2）控制。VLA原语——视觉-语言-动作，一个能看、能读、能动作的统一模型——是连接本阶段理解模型与第15阶段自主系统的桥梁。

**类型：** 学习
**语言：** Python（标准库，动作分词器 + VLA推理骨架）
**先修知识：** 第12阶段·05（LLaVA），第15阶段（自主系统，参考）
**时间：** 约180分钟

## 学习目标

- 描述动作分词化：离散分箱编码（RT-2）、FAST高效动作token、连续流匹配动作（π0）。
- 解释为何在网页+机器人数据上联合微调能保留通用知识向新任务的迁移能力。
- 比较OpenVLA（开源7B Llama+VLM）、π0（流匹配）和GR00T N1（双系统）在相同机器人任务上的表现。
- 说出Open X-Embodiment数据集及其作为RT-X训练语料库的作用。

## 问题所在

机器人能根据自然语言指令做家务，自1970年代以来一直是研究目标。2020年代的答案：视觉-语言-动作（VLA）模型。与VQA所用的VLM架构相同，但输出是动作（关节力矩、末端执行器位姿、离散指令）而非文本。

VLA特有的挑战：

1. 动作空间是连续的（关节角度、力）且高维（7自由度手臂 + 3自由度夹爪 = 10维，30 Hz）。
2. 机器人专用训练数据稀缺。Open X-Embodiment约有100万条轨迹；网页文本-图像数据超过50亿。
3. 控制频率重要。30 Hz控制循环意味着每个动作预算33毫秒。
4. 安全性。错误的动作会损坏硬件、人类或财产。

## 概念

### 动作分词化（RT-2）

RT-2的技巧：将每个关节目标表示为一个量化的文本token。将归一化的[-1, 1]范围离散化为256个分箱，每个分箱映射到一个词汇ID。一个10自由度动作成为每个控制步的10个token。

在混合数据上联合微调PaLM-X VLM：

- 网页图像-文本对（字幕、VQA）。
- 机器人演示，动作用token表示。

模型看到“捡起红色方块”（语言）→ 图像（视觉）→ 10个token的动作序列（离散化的关节目标）。网页预训练保留了通用知识迁移能力：RT-2能执行“朝向快速移动的物体移动”即使“快速移动”不在训练数据中。

RT-2论文中的推理速度为3-5 Hz，受限于VLM自回归解码。

### OpenVLA —— 开源7B参考模型

OpenVLA（Kim等人，2024年6月）是开源权重的RT-2等价物。7B Llama骨干网络，DINOv2 + SigLIP双视觉编码器，256分箱的动作分词化。

在Open X-Embodiment（22个机器人共97万条轨迹）上训练。附带LoRA微调支持，用于适配新机器人。

推理速度：在A100上量化后为4-5 Hz。对慢速操作足够，但不适用于高频控制。

### FAST分词器 —— 更快的动作解码

Pertsch等人（2024年）表明离散分箱分词化效率低下——大多数动作聚集在分箱空间的一个小区域。FAST（频域动作序列分词器）通过DCT压缩动作序列并对系数进行量化。

一个30步的动作轨迹变为约10个FAST token，而非300个离散分箱token。推理速度提升3-5倍且无质量损失。

### π0与流匹配动作

Physical Intelligence的π0（Black等人，2024年10月）用流匹配动作专家替换了离散动作token：

- 一个小型动作变压器读取VLM的隐藏状态，并通过整流流输出一个连续的50步动作序列。
- 动作头使用流匹配损失训练；VLM预训练保持不变。
- 推理：完整动作序列在约5步去噪后输出，实际上为50 Hz控制。

π0的声称：在广泛的操作任务上击败OpenVLA和Octo。连续动作公式保留了离散化破坏的平滑性。

π0.5和π0-FAST是增量升级。π0-FAST将FAST分词化与流匹配相结合。

### GR00T N1 —— 人形机器人双系统

NVIDIA的GR00T N1（2025年3月）专为人形机器人（>30自由度，全身）设计：

- System 2：一个大型VLM读取场景和指令，以约1 Hz的频率产生高层子目标。
- System 1：一个小型动作头变压器，以子目标为条件，产生50-100 Hz的低层关节指令。

这种划分借鉴了Kahneman的快慢思维：System 2规划，System 1动作。优点：慢速VLM规模的规划不会阻塞快速控制；System 1保持小型以降低延迟。

GR00T N1.7（2025年末）改进了数据缩放。GR00T利用来自Omniverse的仿真到真实数据进行微调。

### Open X-Embodiment

训练数据。RT-X（2023年10月）汇集了22个数据集，覆盖22个机器人共100万条轨迹。Open X-Embodiment是每个人使用的语料库：

- ALOHA / Bridge V2 / Droid / RT-2 Kitchen / Language Table。
- 每个样本：（机器人状态、相机视图、指令、动作序列）。
- 训练卫生：统一动作空间、归一化关节范围、调整相机尺寸。

OpenVLA和π0在Open X-Embodiment上训练。通过LoRA在100-1000个任务特定演示上微调，弥补与特定机器人的领域差距。

### 联合微调与纯机器人数据微调

联合微调混合网页VQA数据和机器人轨迹。比例很重要：VQA过多则模型遗忘动作；机器人数据过多则模型失去通用知识。

RT-2的比例：约1:1。OpenVLA：约0.5:1网页比机器人。π0：类似。精确比例是一个需要根据数据集大小调整的超参数。

纯机器人训练产生任务特定模型，会在分布外的指令上失败。联合微调是“捡起红色方块（在演示中）”和“捡起左边第三个最大的物体（新表述）”之间的区别。

### 安全与动作限制

每个生产级VLA都附带：

- 硬关节限制（扭矩不能超出规格）。
- 速度限制（软裁剪）。
- 工作空间边界（末端执行器不能离开桌面）。
- 对新任务的人类在环批准。

这些作为控制层检查位于VLA外部。VLA的输出是建议，而非命令。

## 使用它

`code/main.py`：

- 实现256分箱动作分词化和去分词化。
- 基于DCT+量化勾勒FAST分词器。
- 比较每个动作步的token数（离散分箱、FAST、连续流）。
- 打印RT-2 → OpenVLA → π0 → GR00T的传承总结。

## 交付它

本课产生`outputs/skill-vla-action-format-picker.md`。给定一个机器人任务（操作、导航、人形全身），在离散分箱+RT-2、FAST+OpenVLA、流匹配+π0或双系统+GR00T之间做出选择。

## 练习

1. 一个10自由度手臂以30 Hz控制率运行。256分箱的离散分箱分词化每秒产生多少token？一个7B VLM能跟得上吗？

2. FAST分词化将30步轨迹压缩到约10个token。如果轨迹包含高频运动（例如敲鼓），用户会失去什么？

3. π0的流匹配头在约5步内去噪。比较其吞吐量与OpenVLA自回归解码（4-5 Hz）。

4. GR00T的System 1 / System 2划分映射到Kahneman。提出一个可能有助于双足行走的不同划分（System 3？）。

5. 阅读Open X-Embodiment第4节关于数据集整理的内容。说出防止领域泄漏的三个整理规则。

## 关键术语

| 术语 | 人们说的 | 实际含义 |
|------|----------|----------|
| VLA | "视觉-语言-动作" | 接受图像和指令并输出动作命令的模型 |
| 动作分词化 | "离散分箱" | 将连续关节目标量化为每维256个分箱，每个分箱一个词汇ID |
| FAST分词器 | "频率动作token" | DCT + 量化将30步轨迹压缩到约10个token |
| 联合微调 | "混合网页+机器人" | 在网页VQA数据与机器人演示上联合训练以保留通用知识 |
| 流匹配动作头 | "π0连续输出" | 一个小型变压器通过整流流输出50步动作序列 |
| System 1 / System 2 | "双系统控制" | 大型VLM缓慢规划，小型动作头快速动作；GR00T模式 |
| Open X-Embodiment | "RT-X数据集" | 100万轨迹跨机器人数据集；训练语料库 |
