# 音频-语言模型：从 Whisper 到 Audio Flamingo 3 的演进弧线

> Whisper (Radford 等人，2022年12月) 解决了语音识别问题——68万小时的弱监督多语言语音数据、一个简单的编码器-解码器Transformer、一个让后续所有ASR论文都会引用的基准。但识别不等于推理。要问"这段录音中有哪些乐器"、"说话者表达的是什么情绪"或"第三分钟发生了什么"需要的是音频理解，而非转录。Qwen-Audio、SALMONN、LTU 以及 NVIDIA 的 Audio Flamingo 3（AF3，2025年7月）逐步构建了完整的技术栈：保留 Whisper 类编码器，加装 Q-Former，在音频-文本指令数据上训练，并加入思维链推理。本课程将带你走过这一演进路径。

**类型：** 构建

**语言：** Python（标准库，log-Mel 频谱图 + 音频 Q-Former 框架）

**前置知识：** 阶段6（语音与音频）、阶段12·03（Q-Former）

**时长：** 约180分钟

## 学习目标

- 从波形计算 log-Mel 频谱图：加窗、FFT、滤波器组、对数变换。
- 比较不同的编码器选项：Whisper 编码器、BEATs、AF-Whisper 混合模式。各自在何种场景下占优。
- 构建音频 Q-Former：N 个可学习的查询（queries）与频谱图块进行交叉注意力。
- 解释级联（Whisper 后接 LLM）与端到端音频-LLM 训练的区别：为何端到端在推理上更具扩展性。

## 问题

语音识别已被 Whisper 解决。音频的 OCR 已成为商品。但"商品化"止步于转录。如果模型无法对它听到的内容进行推理——时间、说话人、情绪、音乐结构、环境声音——单靠转录无法驱动产品功能。

三条明显的路线：

1. 级联：Whisper 转录，LLM 对转录文本进行推理。适用于纯语音场景，但在音乐、环境音频、多人重叠语音、情绪分析方面失败。
2. 端到端音频-LLM：音频编码器直接将音频令牌输入到 LLM，跳过转录。保留了声学信息（情绪、说话人、环境），需要新的训练数据。
3. 混合模式：音频编码器 + 文本解码器，既能转录也能推理。Qwen-Audio 和 Audio Flamingo 选择了这条路线。

## 核心概念

### Log-Mel 频谱图：输入特征

每个音频编码器都从同一特征开始：log-Mel 频谱图。

1. 重采样至 16 kHz。
2. 使用 25ms 窗口、10ms 步长进行短时傅里叶变换。
3. 取 FFT 结果的幅值。
4. 应用 Mel 滤波器组（通常为 80 个滤波器，对数间隔 0-8000 Hz）映射到感知频率。
5. 对数压缩（log(1 + x)）以调节动态范围。

结果：一个形状为 (T, 80) 的二维数组，其中 T 是时间帧数。对于 30 秒片段、100 Hz 帧率：(3000, 80)。

### Whisper 编码器

Whisper 编码器是一个 12 层的 ViT 风格 Transformer，将 log-Mel 频谱图作为时间帧序列处理。输出：每个时间帧对应一个隐藏状态向量。

对于 ASR，Whisper 解码器是一个交叉注意力 Transformer，以编码器输出为条件生成文本令牌。标准编码器-解码器架构。

对于 ALM（音频-LLM），需要将编码器输出作为另一个 LLM 的输入。典型模式：Whisper 编码器冻结，Q-Former 可训练，LLM 冻结或微调。

### BEATs 与专用于音频的编码器

Whisper 在以语音为主的数据上训练，因此在音乐和环境音频方面表现较弱。

BEATs（Chen 等人，2022）是一个在 AudioSet 上训练的自监督 Transformer。在参数量相同的情况下，对音乐和环境声音的捕捉能力优于 Whisper。

AF-Whisper（Audio Flamingo 3 的混合方案）：将 Whisper 和 BEATs 的特征拼接作为音频输入。Whisper 承载语言信号，BEATs 承载声学信号。

### 音频 Q-Former

与 BLIP-2 的视觉 Q-Former 模式相同。固定数量的可学习查询（通常为 32 或 64）与音频编码器的输出帧进行交叉注意力。这些查询成为 LLM 使用的音频令牌。

训练对齐阶段：仅训练 Q-Former，在音频-文本对（AudioCaps, Clotho）上使用对比 + 描述损失。指令阶段：端到端，解冻 LLM，在指令数据上训练。

### 演进弧线 — SALMONN、Qwen-Audio、AF3

SALMONN（Tang 等人，2023）：Whisper + BEATs + Q-Former + LLaMA。第一个具有较强推理能力的开源音频-LLM。在 MMAU 基准上的综合得分约 0.55。

Qwen-Audio（Chu 等人，2023）：架构类似，在更丰富的数据集上训练，针对多轮对话进行调优。MMAU 得分约 0.60。

LTU — Listen, Think, Understand（Gong 等人，2023）：使用显式推理数据，专注于对音频片段的思维链推理。规模更小但更专注。

Audio Flamingo 3（Goel 等人，2025年7月）：当前开源 SOTA。8B LLM 骨干（Qwen2 7B），Whisper-large 编码器拼接 BEATs，64 查询 Q-Former，在超过 100 万音频-文本指令对上进行训练。MMAU 0.72，在某些子任务上与闭源前沿模型持平。

AF3 还引入了按需音频思维链：模型可以选择在最终答案前输出思考令牌（例如“让我先确定乐器：...”）。启用思考后，复杂推理任务的准确率提升 3-5 个百分点。

### 级联 vs 端到端

级联管道：

1. Whisper 将音频转录为文本。
2. LLM 对文本进行推理。

对于“总结这个播客”表现完美，但在以下情况失败：
- “这首歌的情绪是什么？”——情绪存在于声音中，而非文字。
- “谁在说话，Alice 还是 Bob？”——需要说话人识别。
- “爆炸发生在第几秒？”——时间定位在文本中丢失。
- “这是真实音频还是生成的音频？”——深度伪造检测需要声学特征。

端到端保留了声学信号。Qwen-Audio 和 AF3 原生处理音乐、环境和情绪。

### 2026年生产环境方案

对于一个新的音频理解产品：

- 如果目标是转录，不涉及音乐和情绪推断，使用级联方案。
- 如果涉及音乐、情绪、多人说话或复杂音频推理，使用 AF3 / Qwen-Audio 系列。

级联更便宜、更简单。端到端能力更强。

### MMAU — 音频推理基准

MMAU（大规模多模态音频理解）是2024-2025年的音频推理基准：

- 10,000 个音频-文本问答对，涵盖语音、音乐、环境声音。
- 涵盖分类、时间推理、因果推理、开放式问答。
- 测试级联管道系统性地遗漏的问题。

开源 SOTA (AF3) 得分0.72；闭源前沿模型约0.78（Gemini 2.5 Pro, Claude Opus 4.7）。差距比 VideoMME 的开源与闭源差异更小，表明音频-LLM 正在成熟。

## 使用它

`code/main.py`：

- 使用标准库实现 log-Mel 频谱图计算：加窗、朴素 DFT、Mel 滤波器组。
- 音频 Q-Former 框架：给定编码器输出帧，计算 Q、K、V、注意力，并输出 N 个令牌。
- 在一个简单任务上比较级联与端到端。

## 交付它

本课程将生成 `outputs/skill-audio-llm-pipeline-picker.md`。给定一个音频任务（转录、音乐标注、情绪推断、多人说话人分离、环境分类），它会选择级联、端到端 AF3 或混合方案。

## 练习

1. 计算 16kHz、25ms 窗口、10ms 步长、80 个 Mel 分箱条件下，30 秒片段的 log-Mel 频谱图维度。在 48kHz 下如何变化？

2. 为什么 Whisper 在音乐上表现不佳？BEATs 捕捉了哪些 Whisper 没有捕捉的音频特征？

3. 音频 Q-Former 使用 64 个查询 vs 32 个：在什么任务复杂度下 64 个更值得？32 个在哪些情况下可以节省计算？

4. 阅读 AF3 第 4 节关于按需思考的内容。提出三个最受益于思维链的音频任务。

5. 使用 AF3 的输出实现一个最小的说话人分离管道。如何标记说话人切换？

## 关键术语

| 术语 | 人们常说的 | 实际含义 |
|------|------------|----------|
| Log-Mel spectrogram | “Mel 特征” | 对数幅度值的 2D (时间, 频率) 数组，经 Mel 滤波器组处理后得到 |
| Audio Q-former | “音频感知器” | 从音频编码器输出到固定长度查询的交叉注意力瓶颈，查询输入给 LLM |
| Cascaded | “ASR 后接 LLM” | Whisper 转录、文本 LLM 推理的管道；丢失声学信息 |
| End-to-end | “音频-LLM” | 音频特征通过 Q-Former 直接进入 LLM；保留声学信号 |
| BEATs | “AudioSet 音频编码器” | 在 AudioSet 上训练的自监督 Transformer；在音乐和环境声音方面表现强 |
| MMAU | “音频推理基准” | 包含 10k 个 QA 对，覆盖语音、音乐、环境；2024 年评估标准 |
| On-demand thinking | “音频 CoT” | 模型可选择在最终答案前输出推理令牌，准确率提升 3-5 个百分点 |
