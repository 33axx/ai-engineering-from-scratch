# StyleGAN

> 大多数生成器将 `z` 同时注入每一层。StyleGAN 将其拆分开来：首先将 `z` 映射到中间表示 `w`，然后通过 AdaIN 在每个分辨率层级*注入* `w`。这一改变解开了潜空间的纠缠，使得照片级人脸生成在过去七年中成为已解决的问题。

**类型：** 构建
**语言：** Python
**前置知识：** 阶段8·03（生成对抗网络），阶段4·08（归一化），阶段3·07（卷积神经网络）
**时间：** 约45分钟

## 问题

DCGAN 通过一系列转置卷积将 `z` 映射为图像。问题在于：`z` 控制一切——姿态、光照、身份、背景——这些属性纠缠在一起。沿着 `z` 的一个轴移动，所有四个属性都会变化。你无法向模型提出“同一个人，不同姿态”的要求，因为表示没有以那种方式分解。

Karras 等人（2019，NVIDIA）提出：停止将 `z` 直接馈入卷积层。而是将一个恒定的 `4×4×512` 张量作为网络输入。学习一个8层 MLP，将 `z ∈ Z → w ∈ W`。通过*自适应实例归一化*（AdaIN）在每个分辨率处注入 `w`：对每个卷积特征图进行归一化，然后通过 `w` 的仿射投影进行缩放和平移。添加每层噪声以处理随机细节（皮肤毛孔、发丝）。

结果：`W` 具有大致正交的轴，分别对应“高层风格”（姿态、身份）和“细粒度风格”（光照、颜色）。你可以通过使用图像 A 的 `w` 用于低分辨率层，图像 B 的 `w` 用于高分辨率层，从而在两幅图像之间交换风格。这解锁了编辑、跨域风格化以及整个“StyleGAN 反演”研究路线。

## 概念

![StyleGAN：映射网络 + AdaIN + 每层噪声](../assets/stylegan.svg)

**映射网络。** `f: Z → W`，一个8层 MLP。`Z = N(0, I)^512`。`W` 不强制为高斯分布——它学习与数据相适应的形状。

**合成网络。** 从一个可学习的恒定 `4×4×512` 开始。每个分辨率块：`上采样 → 卷积 → AdaIN(w_i) → 噪声 → 卷积 → AdaIN(w_i) → 噪声`。分辨率逐倍增加：4、8、16、32、64、128、256、512、1024。

**AdaIN。**

```
AdaIN(x, y) = y_scale · (x - mean(x)) / std(x) + y_bias
```

其中 `y_scale` 和 `y_bias` 来自 `w` 的仿射投影。对每个特征图进行归一化，然后重新风格化。这里的“风格”指的是特征图的一阶和二阶统计量。

**每层噪声。** 单通道高斯噪声添加到每个特征图，由可学习的每通道因子缩放。控制随机细节而不影响全局结构。

**截断技巧。** 在推理时，采样 `z`，计算 `w = mapping(z)`，然后 `w' = ŵ + ψ·(w - ŵ)`，其中 `ŵ` 是许多样本上的平均 `w`。`ψ < 1` 用多样性换取质量。几乎每个 StyleGAN 演示都使用 `ψ ≈ 0.7`。

## StyleGAN 1 → 2 → 3

| 版本 | 年份 | 创新 |
|------|------|------|
| StyleGAN | 2019 | 映射网络 + AdaIN + 噪声 + 渐进式增长。 |
| StyleGAN2 | 2020 | 权重解调取代 AdaIN（修复液滴伪影）；跳跃/残差架构；路径长度正则化。 |
| StyleGAN3 | 2021 | 无混叠卷积 + 等变核；消除纹理粘附在像素网格上的问题。 |
| StyleGAN-XL | 2022 | 类条件，1024²，ImageNet。 |
| R3GAN | 2024 | 以更强的正则化重新命名；在 FFHQ-1024 上以 20 倍少的参数缩小了与扩散模型的差距。 |

到 2026 年，StyleGAN3 仍然是以下场景的默认选择：(a) 高 FPS 下的窄域照片级真实感， (b) 小样本域适应（用 100 张图像在新数据集上训练，冻结映射网络），(c) 基于反演的编辑（找到重构真实照片的 `w`，然后编辑该 `w`）。对于开放域文生图，它不是合适的工具——扩散模型才是。

## 构建

`code/main.py` 实现了一个玩具“style-GAN lite”在一维情况：一个映射 MLP，一个合成函数，它接受一个可学习的恒定向量并通过从 `w` 导出的缩放/偏移对其进行调制，以及每层噪声。它展示了通过仿射调制注入 `w` 能够匹配或超过将 `z` 连接进生成器输入的方法。

### 步骤1：映射网络

```python
def mapping(z, M):
    h = z
    for i in range(num_layers):
        h = leaky_relu(add(matmul(M[f"W{i}"], h), M[f"b{i}"]))
    return h
```

### 步骤2：自适应实例归一化

```python
def adain(x, w_scale, w_bias):
    mu = mean(x)
    sd = std(x)
    x_norm = [(xi - mu) / (sd + 1e-8) for xi in x]
    return [w_scale * xi + w_bias for xi in x_norm]
```

每特征图的缩放和偏移来自 `w` 通过线性投影。

### 步骤3：每层噪声

```python
def add_noise(x, sigma, rng):
    return [xi + sigma * rng.gauss(0, 1) for xi in x]
```

每通道的 sigma 是可学习的。

## 陷阱

- **液滴伪影。** StyleGAN 1 在特征图中产生了块状液滴，因为 AdaIN 将均值归零。StyleGAN 2 的权重解调通过缩放卷积权重而非激活值来修复此问题。
- **纹理粘附。** StyleGAN 1 和 2 的纹理跟随像素坐标，而不是物体坐标（在插值时可见）。StyleGAN 3 的无混叠卷积通过窗口化 sinc 滤波器修复了这个问题。
- **模式覆盖。** 截断 `ψ < 0.7` 看起来干净，但采样自一个狭窄的锥体；如果需要多样性，请使用 `ψ = 1.0`。
- **反演是有损的。** 将真实照片反演到 `W` 通常通过优化或编码器（e4e, ReStyle, HyperStyle）完成。多次迭代后结果会发生漂移。

## 使用

| 用例 | 方法 |
|------|------|
| 照片级人脸（动漫、产品、窄域） | StyleGAN3 FFHQ / 自定义微调 |
| 从照片进行面部编辑 | e4e 反演 + StyleSpace / InterFaceGAN 方向 |
| 换脸 / 表情迁移 | StyleGAN + 编码器 + 混合 |
| 虚拟形象管线 | StyleGAN3 搭配 ADA 进行低数据量微调 |
| 从少量图像进行域适应 | 冻结映射网络，微调合成网络 |
| 多模态或文本条件生成 | 不要用——使用扩散模型 |

对于“人物脸部照片”这类产品级演示，StyleGAN 在推理成本（单次前向传播，4090 上小于 10 毫秒）和相同质量下的清晰度方面优于扩散模型。

## 练习

1. **简单。** 运行 `code/main.py`，分别设置 `adain_on=True` 和 `adain_on=False`。比较在固定潜变量与扰动潜变量下输出的分布。
2. **中等。** 实现混合正则化：对于一个训练批次，计算 `w_a`、`w_b`，在合成的前半部分应用 `w_a`，后半部分应用 `w_b`。解码器是否学到了解耦的风格？
3. **困难。** 取一个预训练的 StyleGAN3 FFHQ 模型（ffhq-1024.pkl）。通过在有标签样本上训练 SVM 找到控制“微笑”的 `w` 方向；报告在身份漂移之前可以推多远。

## 关键术语

| 术语 | 人们常说的 | 实际含义 |
|------|-----------|----------|
| 映射网络 | “MLP” | `f: Z → W`，8层，将潜变量几何与数据统计解耦。 |
| W 空间 | “风格空间” | 映射网络的输出；大致解耦。 |
| AdaIN | “自适应实例归一化” | 归一化特征图，然后通过 `w` 投影进行缩放+平移。 |
| 截断技巧 | “Psi” | `w = mean + ψ·(w - mean)`，ψ<1 用多样性换质量。 |
| 路径长度正则化 | “PL reg” | 惩罚每单位 `w` 变化导致的图像剧烈变化；使 `W` 更平滑。 |
| 权重解调 | “StyleGAN2 修复” | 对卷积权重而非激活值进行归一化；消除液滴伪影。 |
| 无混叠 | “StyleGAN3 的技巧” | 窗口化 sinc 滤波器；消除纹理粘附在像素网格上。 |
| 反演 | “为真实图像找到 w” | 优化或编码 `x → w` 使得 `G(w) ≈ x`。 |

## 生产环境说明：为何 StyleGAN 在 2026 年仍在交付

StyleGAN3 在 4090 上生成 1024² 的 FFHQ 人脸耗时小于 10 毫秒——`num_steps = 1`，无需 VAE 解码，无需交叉注意力计算。在生产环境中，这是任何图像生成器的底层延迟。对于相同分辨率，50 步的 SDXL + VAE 解码管线大约需要 3 秒。这是一个 **300 倍的差距**，对于窄域产品（虚拟形象服务、身份证件管线、库存人脸生成），它在总拥有成本上胜出。

两个操作上的结论：

- **无需调度器，无需批处理。** 目标占用率下的静态批处理是最优的。连续批处理（对 LLM 和扩散模型至关重要）没有任何好处，因为每个请求的 FLOPs 相同。
- **截断 `ψ` 是安全旋钮。** `ψ < 0.7` 从映射网络范围的一个狭窄锥体内采样。这是服务层控制样本方差的唯一杠杆。在峰值负载时降低 `ψ`，为高级用户提高 `ψ`。
