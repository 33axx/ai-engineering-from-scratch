# 心智社会与多智能体辩论

> Minsky 在 1986 年提出的前提——智能是专业智能体的社会——每十年就会被重新发现一次。2023 年，Du 等人将其转化为一个具体的算法：多个 LLM 实例提出答案，相互阅读彼此的答案，进行批判并更新。经过 N 轮迭代，它们收敛到一个共识，这一共识在六项推理和事实性任务上超越了零样本 CoT 和反思。两项发现很重要：**多智能体**和**多轮讨论**各自独立地做出贡献。这个心智社会胜过单智能体独白；多轮交流胜过一次性投票。

**类型**：学习 + 构建  
**语言**：Python（stdlib）  
**先决条件**：阶段 16 · 04（原始模型）  
**时间**：约 60 分钟

## 问题

自洽性——对同一个模型多次采样并取多数答案——是你能想到的最廉价的推理改进手段。它有效但会迅速饱和。你可能将样本数量翻倍，却看不到另一个有意义的提升。

辩论打破了这种饱和。不是从一个模型得到 N 个独立样本，而是 N 个智能体相互阅读彼此的推理并修改。样本之间的相关性降低了（它们不再是独立同分布），而收敛点往往在独立同分布投票自信地给出错误答案时是正确的。

## 概念

### Du 等人 2023 年算法

来自 arXiv:2305.14325（ICML 2024）：

1. N 个智能体各自对问题产生一个初始答案。
2. 对于第 r = 2..R 轮：向每个智能体展示其他智能体在第 r-1 轮的答案，并要求“考虑到这些，给出你更新后的答案”。
3. R 轮之后，对最终答案进行多数投票。

论文在 MMLU、GSM8K、传记、MATH 和事实性基准上进行了测试。辩论始终优于 CoT 和自反思。

### 两个独立控制旋钮

同一篇论文的消融实验：

- **仅增加智能体数量**（1 轮，N 个智能体的多数投票）在大多数任务上优于单智能体，但会进入平台期。
- **仅增加轮数**（一个智能体看到自己之前的推理）几乎没有帮助——这是反思的已知弱点。
- **两者同时使用**产生了巨大的提升。多智能体之间的多轮交流驱动了增益。

### 为什么有效

两种机制：

1. **暴露于分歧**。当一个智能体看到另一个智能体带有不同结论的推理链时，它要么必须证明自己的观点，要么更新。无论哪种方式，第 r+1 轮的上下文都比第 r 轮更丰富。
2. **相关错误减少**。在自洽性中，所有样本来自同一个模型，因此错误是相关的——你平均出一个自信的错误答案。不同的模型或不同的种子会去相关。不同的*辩论观点*进一步去相关。

### 异质辩论

A-HMAD 及其后续工作为不同智能体使用*不同的基础模型*。Llama + Claude + GPT 之间的辩论减少了单一文化崩溃（第 26 课），因为一个模型族的相关错误不会被其他模型族共享。

缺点：一个弱模型参与辩论可能会将共识拖向它的错误答案（参见“Should we be going MAD?”, arXiv:2311.17371）。

### NLSOM——129 个智能体的扩展

Zhuge 等人（“Mindstorms in Natural Language-Based Societies of Mind”，arXiv:2305.17066）将这一思想扩展到包含 129 个成员的心智社会。结果是：随着规模的扩大，专业化和自组织出现，系统在视觉问答等任务上优于单智能体。

### 失败模式

- **阿谀奉承级联**。所有智能体都听信听起来最自信的那个。辩论崩溃为最强声音。提示对抗性角色（“一个智能体必须反驳对方”）有帮助。
- **主题偏离**。多轮辩论会偏离原始问题。缓解方法：每一轮重新注入问题。
- **计算量暴增**。N 个智能体 × R 轮 = N·R 次 LLM 调用，每次调用的上下文规模不断增长。5 个智能体、5 轮的辩论就是 25 次调用，上下文持续增长。每个问题的成本可能超过单次 CoT 调用的 10 倍。

## 构建它

`code/main.py` 运行一个 3 智能体 × 3 轮的辩论，针对一个数学问题，每个智能体从一个不同的（可能是错误的）答案开始。智能体是脚本化的——每个智能体通过一次辩论邻居的答案（加权平均）来“更新”，权重基于脚本化的置信度。收敛在逐轮日志中可见。

该演示展示了两个关键效果：

- 单轮交流使智能体更接近正确答案。
- 超过第 2 轮后额外的轮次显示出收益递减（与 Du 等人的平台期一致）。

运行：

```
python3 code/main.py
```

## 使用它

`outputs/skill-debate-configurator.md` 为新的任务配置辩论：智能体数量、轮数、异质性（相同模型 vs 混合）、角色分配（对称 vs 一个对抗性角色）。它还会在运行前估算 token 成本。

## 交付它

如果你要交付辩论系统：

- **轮数上限设为 3**。Du 等人表明 3 轮捕获了大部分增益。更多轮次只是增加成本，而非质量。
- **智能体数量上限设为 5**。超过 5 个，上下文膨胀和成本会占主导。
- **默认使用异质性**。池中至少有两个不同的基础模型。
- **设置一个对抗性插槽**。提示一个智能体无论如何都要反对。打破阿谀奉承。
- **记录每一轮**。隐藏中间轮的辩论系统无法被调试或审计。

## 练习

1. 运行 `code/main.py`，然后将轮数设为 5，观察收益递减。在那一轮之后额外的收敛停止了？
2. 添加第四个智能体，角色为对抗性：始终反对当前的多数。这会破坏还是改善收敛？
3. 绘制（打印）每轮的一致性分数（处于多数答案的智能体比例）。它在何时达到 1.0，这是否等同于“正确”？
4. 阅读 Du 等人论文第 4 节的消融实验。使用此代码重现“仅智能体” vs “仅轮次” vs “两者”的结果。
5. 阅读“Should we be going MAD?”（arXiv:2311.17371），并列举轮询之外的两种辩论变体——例如，裁判主导、辩论链、对抗性辩论。

## 关键术语

| 术语 | 常说的意思 | 实际含义 |
|------|------------|----------|
| 心智社会 | “Minsky 的想法” | 智能作为相互作用的专业智能体；1986 年的框架现在通过 LLM 辩论得以操作化。 |
| 多智能体辩论 | “智能体争论” | N 个智能体提出、相互批评、修改、经过 R 轮后多数投票。 |
| 共识 | “他们达成一致” | 不是认识论上的真理——只是在多数答案上的分数比例。可能是自信地错误。 |
| 轮次 | “交流步骤” | 一轮 = 每个智能体阅读其他智能体并更新一次。 |
| 异质辩论 | “混合模型族” | 使用不同基础模型以使错误去相关。 |
| 阿谀奉承级联 | “每个人都同意那个最响亮的” | 辩论失败：智能体服从于最自信的智能体，无论其正确性。 |
| NLSOM | “129 智能体社会” | 基于自然语言的心智社会；Zhuge 等人的扩展版本。 |
| 相关错误 | “相同模型，相同错误” | 自洽性饱和的原因；跨不同观点的辩论使其去相关。 |
