# 指令遵循作为对齐信号

> 后来对RLHF的每一条批评都在反对这个流程。在研究优化压力如何扭曲代理指标之前，你必须先看到代理指标是什么。InstructGPT（Ouyang 等人，2022）定义了参考架构：在指令-响应对上进行监督微调，基于成对偏好排序训练奖励模型，以及以KL惩罚约束SFT策略的PPO优化。一个1.3B参数的InstructGPT竟然优于175B参数的GPT-3。正是这个单一结果解释了为什么在2026年，每个前沿实验室仍然沿用RLHF形状的后训练流程。

**类型：** 学习
**语言：** Python（标准库，简易三阶段流程）
**前置要求：** 阶段10·06（SFT），阶段10·07（RLHF），阶段10·08（DPO）
**时间：** 约45分钟

## 学习目标

- 指出InstructGPT流程的三个阶段及每个阶段使用的损失函数。
- 解释为什么一个1.3B参数的指令微调模型在人类偏好评估中战胜了原始的175B GPT-3。
- 说明第三阶段中KL惩罚保护的是什么，以及为什么移除它会退化为模式寻求行为。
- 描述对齐税以及Ouyang等人用来缓解这一问题的PPO-ptx方法。

## 问题

预训练语言模型完成文本。它们不回答问题。让GPT-3“写一个反转列表的Python函数”，你通常得到的是另一个提示，因为大部分训练分布是继续输出更多网络文本的网络文本。模型在完成它的工作——但工作本身就是错的。

每个严肃实验室用来解决这个问题的代理指标是人类偏好。两个补全结果交给评分员；评分员选出更好的那一个；奖励模型学习评分员的偏好。然后RL循环将策略推向奖励模型评分高的输出。这三句话就是完整的InstructGPT论文论点。论文的其余部分是工程实现。

## 概念

### 阶段1：监督微调（SFT）

收集提示-响应对，其中响应是善意的人类会写的内容。Ouyang等人使用了来自标注员和OpenAI API的1.3万个提示。在标准交叉熵损失下，在此数据上微调基础模型。

**SFT带来的结果：** 模型现在回答问题而不是延续它们。**SFT无法带来的结果：** 当多个回答都合理时，没有信号表明评分员偏好哪一个。

### 阶段2：奖励模型（RM）

对于每个提示，从SFT模型中采样K个补全结果。标注员对它们进行排序。训练一个奖励模型，对任何提示-响应对进行评分，使得当 `y_w` 比 `y_l` 更受偏好时：

```
L_RM = -log sigmoid(r(x, y_w) - r(x, y_l))
```

这就是Bradley-Terry成对偏好损失。RM通常从SFT模型初始化，用标量头替换LM头。

奖励模型很小：对于175B的InstructGPT，6B已经足够。它们也很脆弱——论文第5节主要描述了小规模下出现的奖励破解行为。

### 阶段3：带KL惩罚的PPO

定义目标：

```
J(pi) = E_{x~D, y~pi(.|x)} [ r(x, y) ] - beta * KL(pi(.|x) || pi_SFT(.|x))
```

使用PPO最大化。KL项防止 `pi` 远离SFT策略。没有它，优化器会找到对抗性样本——那些在RM下得分很高的字符串，因为RM从未见过它们，而非因为人类真的更偏好它们。

KL系数 `beta` 是RLHF中最重要的单一超参数。太低：奖励破解。太高：相对于SFT没有改进。

### 对齐税

经过RLHF后，模型虽然更受人类偏好，但在标准基准（SQuAD、HellaSwag、DROP）上出现退化。Ouyang等人称之为对齐税，并通过PPO-ptx加以缓解：将预训练梯度混合到RL目标中，使模型不会忘记它从未因之获得奖励的下游任务。

```
J_ptx(pi) = J(pi) + gamma * E_{x~D_pretrain} [ log pi(x) ]
```

PPO-ptx成为了标准。Anthropic、DeepMind和Meta都使用了某种变体。

### 结果

一个1.3B的InstructGPT（SFT + RM + PPO-ptx）在约70%的情况下被标注员认为优于175B的基础GPT-3。在来自生产流量的隐藏测试提示上，差距进一步扩大。从这个数字中可以得到两点启示：

1. 对齐与能力是不同的维度。175B模型拥有更多能力，而1.3B模型更对齐；标注员更偏好对齐的模型。
2. 能力下限由基础模型设定。你无法通过RLHF将一个基础模型变成它从未见过的事实知识的专家。

### 为什么这是阶段18的参考点

之后每一课中的批评——奖励破解（第2课）、DPO（第3课）、谄媚（第4课）、CAI（第5课）、休眠智能体（第7课）、对齐伪装（第9课）——都在反对这个流程的某一部分。奖励破解攻击阶段2。DPO将阶段2和阶段3合并。CAI替换了人类标注员。谄媚表明标注员是一个有偏的信号。对齐伪装表明策略可以完全绕过阶段3。如果不先把流程记在脑子里，你就无法理解这些批评中的任何一条。

## 使用它

`code/main.py` 在玩具偏好数据上模拟三个阶段。基础“策略”是一个在动作{A, B, C}上的有偏硬币。阶段1的SFT在200个提示上模仿标注员动作。阶段2从500个成对排名中拟合一个Bradley-Terry奖励模型。阶段3运行一个简化的PPO更新，带有对SFT策略的KL惩罚。你可以观察奖励升高、KL散度增长以及策略偏移——而且你可以关闭KL项，看在50个更新步内奖励破解如何出现。

关注点：

- 参数 `beta = 0.1` 对比 `beta = 0.0` 时的奖励轨迹。
- 训练步骤中 KL(pi || pi_SFT) 的变化。
- 最终动作分布与标注员偏好的对比。

## 发布它

本课产出 `outputs/skill-instructgpt-explainer.md`。给定一个RLHF流程描述或论文摘要，它能够识别三个阶段中哪一个被修改、每个阶段使用了什么损失函数，以及是否存在KL惩罚或等效正则化器。

## 练习

1. 运行 `code/main.py`。将 `beta` 设为 `0.0`，报告200步PPO后的动作分布。用一段话解释模式寻求行为。

2. 修改奖励模型，使其对动作B有+0.5的偏置（模拟奖励错误）。以 `beta = 0.1` 运行PPO。KL惩罚是否阻止策略利用这个偏置？在哪个 `beta` 值下，利用变得可见？

3. 阅读Ouyang等人（arXiv:2203.02155）的图1。运行PPO 1、5、20、100步，并测量相对于SFT模型的偏好率，重现标注员偏好曲线。

4. 论文第4.3节报告，1.3B的InstructGPT在约70%的情况下击败175B的GPT-3。为什么在生产环境的隐藏提示上这个比率会比在标注员自己的提示上更高？

5. 将PPO损失替换为DPO（阶段10·08），在相同的偏好数据上运行。比较最终策略偏移（KL到SFT）和最终奖励。在匹配奖励下，哪种方法偏移得更远？

## 关键词

| 术语 | 人们说的 | 实际含义 |
|------|---------|----------|
| SFT | “指令微调” | 阶段1：在提示-响应对上进行交叉熵微调 |
| 奖励模型 | “RM” | 在（提示，响应）上的标量回归器，使用Bradley-Terry损失在成对标签上训练 |
| Bradley-Terry | “成对偏好损失” | -log sigmoid(r_w - r_l)；将成对排名简化为二分类 |
| KL惩罚 | “正则化器” | `beta * KL(pi || pi_SFT)` —— 保持RL策略接近SFT锚点 |
| PPO-ptx | “带预训练混合的PPO” | 在PPO目标中添加一部分预训练对数似然，以抵消对齐税 |
| 对齐税 | “RLHF退化” | RLHF后标准基准上的下降，因为RLHF并未针对它们 |
| 标注员偏好 | “真实标签” | 人类排名的样本；RM是其统计代理，而非“人类价值观” |
