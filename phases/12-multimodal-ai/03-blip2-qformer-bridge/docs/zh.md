# 从CLIP到BLIP-2 — 将Q-Former作为模态桥梁

> CLIP能够对齐图像和文本，但无法生成描述、回答问题或进行对话。BLIP-2（Salesforce，2023年）通过一个可训练的小型桥梁解决了这个问题：32个可学习的查询向量通过交叉注意力关注冻结的ViT特征，然后直接插入到冻结的LLM的输入流中。188M参数的桥梁连接了一个11B的LLM和一个ViT-g/14。直到2026年，所有基于适配器的VLM——MiniGPT-4、InstructBLIP、LLaVA的衍生模型——都是它的后代。本课将解读Q-Former的架构，解释其两阶段训练，并构建一个玩具版本，将视觉令牌馈送到冻结的文本解码器中。

**类型：** 构建  
**语言：** Python（stdlib，交叉注意力+可学习查询演示）  
**先修知识：** 阶段12·02（CLIP），阶段7（Transformer）  
**时间：** 约180分钟

## 学习目标

- 解释为什么在冻结的视觉编码器和冻结的LLM之间使用可训练的瓶颈在成本和稳定性上优于端到端微调。
- 实现一个交叉注意力块，其中一组固定的可学习查询关注外部图像特征。
- 讲解BLIP-2的两阶段预训练：表示学习（ITC + ITM + ITG）然后是生成学习（带冻结解码器的LM损失）。
- 将Q-Formatter与LLaVA中使用的更简单的MLP投影器进行比较，并论证每种选择何时胜出。

## 问题

你有一个冻结的ViT，每张图像产生256个patch令牌，维度为1408。你有一个冻结的7B LLM，期望令牌嵌入维度为4096。明显的桥梁——将1408线性映射到4096——是可行的，但将所有256个patch令牌馈送到LLM的上下文需要每张图像额外消耗256个令牌。在32张图像的批次中，仅视觉模态就消耗了8192个令牌。

BLIP-2的问题：能否将256令牌的图像表示压缩为少得多的令牌（例如32个），同时保留足够的信息供LLM进行描述、回答问题和对图像进行推理？能否在不触及冻结主干的情况下训练这个桥梁，将训练成本限制在桥梁的参数上？

答案是：Q-Former。32个可学习的“查询”向量交叉关注ViT的patch令牌，产生一个32令牌的视觉摘要，供LLM使用。总共188M参数。在接触LLM之前，使用对比、匹配和生成目标进行训练。

## 概念

### 可学习查询

Q-Former的核心技巧：不是让LLM的文本令牌关注图像补丁，而是引入一组新的32个可学习查询向量`Q`，让*它们*关注图像补丁。这些查询是模型的参数——它们在训练期间学习，并且相同的32个查询用于每张图像。

经过交叉注意力后，每个查询都包含图像的一个压缩摘要——“描述主要物体”、“描述背景”、“数物体的数量”等。这些查询并非字面上专门化于语义标签；它们学习任何使下游损失下降的编码。

### 架构

Q-Former是一个小型Transformer（12层，约100M参数），具有两条路径：

1. 查询路径：32个查询向量依次经过自注意力（彼此之间）、对冻结ViT的patch令牌的交叉注意力、然后FFN。
2. 文本路径：一个类似BERT的文本编码器与查询路径共享自注意力和FFN权重。文本路径禁用交叉注意力。

训练时两条路径都运行。查询和文本通过共享的自注意力交互，这意味着查询可以在需要时（ITM、ITG）根据文本进行条件调整。在推理时用于VLM交接，只有查询流过，产生32个视觉令牌。

### 两阶段训练

BLIP-2分两个阶段进行预训练：

第一阶段：表示学习（无LLM）。三个损失：
- ITC（图像-文本对比）：CLIP风格的对比损失，在池化的查询令牌和文本CLS令牌之间。
- ITM（图像-文本匹配）：二元分类器——这个图像-文本对是否匹配？使用硬负样本挖掘。
- ITG（基于图像的文本生成）：文本上的因果LM头，以查询为条件。迫使查询编码可生成文本的内容。

只有Q-Former训练。ViT冻结。不涉及LLM。

第二阶段：生成学习。附加一个冻结的LLM（OPT-2.7B或Flan-T5-XL等）。通过一个小的线性层将32个查询输出投影到LLM的嵌入维度。将它们前置到文本提示前。仅训练线性投影和Q-Former，使用连接后的提示+图像+描述序列上的LM损失。

第二阶段之后，Q-Former + 投影构成了完整的视觉适配器。推理时：图像 → ViT → Q-Former → 线性投影 → 前置到文本 → 冻结的LLM生成输出。

### 参数经济学

带有ViT-g/14（冻结1.1B）+ OPT-6.7B（冻结6.7B）+ Q-Former（训练188M）的BLIP-2总参数量为8B，其中188M被训练。Q-Former本身约占完整堆栈参数的2.4%。训练成本反映了这一点：在几个A100上训练数天，而端到端需要数周。

质量：BLIP-2在零样本VQA上匹配或超越Flamingo-80B，同时体积小50倍。这个桥梁有效。

### InstructBLIP和指令感知的Q-Former

InstructBLIP（2023）为Q-Former增加了一个额外输入：指令文本本身。在交叉注意力时，查询现在既可以访问图像补丁也可以访问指令。查询可以针对每个指令（“数汽车”、“描述情绪”）进行专门化，而不是学习一个固定的摘要。在保留任务上的基准测试有所提升。

### MiniGPT-4和仅投影器方法

MiniGPT-4保留了Q-Former，但只训练输出线性投影，同时冻结其他所有内容。成本低，但代价是质量——查询是BLIP-2的，而不是你自己的。适合快速迭代，但不是最佳架构。

### 为什么LLaVA走向更简单的方案

LLaVA（2023年，第12.05课）用简单的两层MLP取代了Q-Former，该MLP将每个ViT patch令牌投影到LLM空间——对于24x24的网格，每张图像576个令牌，全部馈送到LLM。压缩更差，但允许LLM关注原始补丁。当时这引起了争议；到2023年末，它成为主流，因为视觉指令数据（LLaVA-Instruct-150k）证明MLP可以训练到保留足够信号。权衡：LLaVA的上下文填充更快，但它自然扩展到多图像和视频。

到2026年，该领域分裂：Q-Former在令牌预算紧张时（长视频、多图像）存活；MLP投影器在每令牌原始质量优先时占主导。

### 门控交叉注意力：Flamingo，祖先

Flamingo（第12.04课）早于BLIP-2，并在每个冻结的LLM层使用相同的交叉注意力思想，而不是作为单个桥梁。BLIP-2表明可以压缩到仅输入层仍然有效。Gemini和Idefics结合了两者：交错的输入令牌加上可选的用于上下文少样本的门控交叉注意力。

### 2026年的后代

- Q-Former：BLIP-2、InstructBLIP、MiniGPT-4以及大多数视频-语言模型（出于令牌预算原因）。
- Perceiver重采样器：Flamingo的变体（第12.04课）；Idefics系列、Eagle、OmniMAE。
- MLP投影器：LLaVA、LLaVA-NeXT、LLaVA-OneVision、Cambrian-1。
- 注意力池化：VILA、PaliGemma。

所有四种都是有效的。决定性问题是：你是受限于令牌预算还是每令牌质量。

## 使用它

`code/main.py` 构建了一个stdlib风格的Q-Former交叉注意力：

1. 模拟256个图像patch令牌（维度128）。
2. 实例化32个可学习查询（维度128）。
3. 运行缩放点积交叉注意力（查询来自查询，键/值来自补丁）。
4. 通过线性层投影到LLM维度（512）。
5. 输出32个LLM就绪的视觉令牌。

所有数学运算均使用纯Python（向量的嵌套循环）。玩具实现但形状正确。打印注意力权重矩阵，以便查看每个查询从哪些补丁中提取信息。

## 关键术语

| 术语 | 人们所说的 | 实际含义 |
|------|-----------|---------|
| Q-Former | “查询型Transformer” | 小型Transformer，具有32个可学习查询向量，交叉关注冻结的ViT特征 |
| 可学习查询 | “视觉的软提示” | 一组固定的参数，作为交叉注意力的查询方；每个模型学习，所有输入共享 |
| 交叉注意力 | “查询来自这里，键/值来自那里” | 查询、键、值来自不同源的注意力；查询如何从ViT补丁中提取信息 |
| ITC | “图像-文本对比” | CLIP风格的损失，应用于Q-Former池化查询与文本CLS之间 |
| ITM | “图像-文本匹配” | 对硬负样本挖掘对进行二元分类；迫使查询区分细粒度不匹配 |
| ITG | “基于图像的文本生成” | 因果LM损失，文本以查询为条件生成；迫使查询编码可解码为文本的内容 |
| 两阶段预训练 | “表示学习然后生成学习” | 第一阶段单独训练Q-Former（ITC/ITM/ITG）；第二阶段附加冻结的LLM，仅训练投影+Q-Former |
| 冻结主干 | “不要微调” | 视觉编码器和LLM权重固定；只有桥梁训练 |
| 投影头 | “线性到LLM维度” | 最终线性层，将Q-Former输出映射到LLM的嵌入维度 |
| Perceiver重采样器 | “Flamingo的版本” | 类似的可学习查询交叉注意力，Flamingo在每一层使用，而不是作为单个桥梁 |
