# 图像基础——像素、通道、色彩空间

> 图像是光样本的张量。你今后使用的每一个视觉模型都基于这一事实。

**类型：** 构建
**语言：** Python
**前置要求：** 第一阶段第12课（张量运算），第三阶段第11课（PyTorch入门）
**时长：** 约45分钟

## 学习目标

- 解释连续场景如何被离散化为像素，以及采样/量化决策如何为所有下游模型设置上限
- 将图像作为 NumPy 数组读取、切片和检查，并在 HWC 和 CHW 布局之间流畅切换
- 在 RGB、灰度图、HSV 和 YCbCr 之间进行转换，并论证每种色彩空间存在的理由
- 完全按照 torchvision 的期望应用像素级预处理（归一化、标准化、调整大小、通道优先）

## 问题

你即将阅读的每一篇论文、下载的每一个预训练权重、调用的每一个视觉 API 都假定输入采用特定的编码方式。将一个 `uint8` 图像传入需要 `float32` 输入的模型，它仍然会运行——然后静默地产生垃圾结果。向基于 RGB 训练的网络传入 BGR，准确率会下降十个百分点。将一个通道在最后的输入交给期望通道优先的模型，第一个卷积层会把高度当作特征通道。这些情况都不会抛出错误。它们只会在暗中破坏你的指标，然后你花一整周的时间寻找一个存在于文件加载方式中的 bug。

一旦你知道卷积在滑动什么，它并不复杂。难点在于“图像”对相机、JPEG 解码器、PIL、OpenCV、torchvision 和 CUDA 内核来说意义不同。每个栈都有自己的轴顺序、数值范围和通道约定。一个无法理清这些区别的视觉工程师会输出有问题的流水线。

本节课夯实基础，以便后续课程可以构建其上。学完本课，你将知道什么是像素、为什么每个像素有三个数字而不是一个、“用 ImageNet 统计量标准化”实际上做了什么，以及如何在后续课程中会假设的两三种布局之间进行切换。

## 概念

### 完整的预处理流水线概览

每个生产级视觉系统都是由一系列可逆变换组成的相同序列。任何一步出错，模型就会看到与训练时不同的输入。

```python
# 相机/磁盘 → 原始 uint8 → 归一化 [0,1] → 标准化（均值/方差）→ 通道优先布局 → 模型
#                   ^                                        ^
#         此处容易遗漏 / 255                此处容易忘记减去均值
```

两个红色和蓝色框是 80% 静默失败的根源：缺少标准化和布局错误。

### 像素是一个样本，而不是一个方块

相机传感器统计落在微小探测器网格上的光子数量。每个探测器在极短时间内对光进行积分，并产生一个与撞击光子数成正比的电压。传感器随后将该电压离散化为一个整数。一个探测器变成一个像素。

```python
# 场景 → 空间采样 → 强度量化 → 像素值
#        (网格密度)    (位深)
```

在这个步骤中发生两个选择，它们为后续所有内容设定了上限：

- **空间采样** 决定每度场景有多少探测器。太少，边缘会变得锯齿状（混叠）。太多，存储和计算会爆炸。
- **强度量化** 决定电压被分桶的精细程度。8 位提供 256 个级别，是显示的标准。10、12、16 位提供更平滑的渐变，对于医学成像、HDR 和原始传感器流水线很重要。

像素不是带有面积的有色方块。它是一个单一的测量值。当你调整大小或旋转时，你是在重新采样那个测量网格。

### 为什么是三个通道

一个探测器统计整个可见光谱的光子——这是灰度图。为了获得颜色，传感器在网格上覆盖红、绿、蓝滤光片的马赛克。经过去马赛克后，每个空间位置都有三个整数：附近红色滤光探测器、绿色滤光和蓝色滤光探测器的响应。这三个整数就是一个像素的 RGB 三元组。

```python
# 每个空间位置 (x, y) 都有一个三元组 [R, G, B] 或更一般地，每个位置一个多值向量
image[H, W, C]    # 对于标准相机，C = 3
```

三不是魔法。深度相机增加 Z 通道。卫星增加红外和紫外波段。医学扫描通常有一个通道（X 光、CT）或多个通道（高光谱）。通道数是最后一个轴；卷积层学习跨越通道进行混合。

### 两种布局约定：HWC 和 CHW

相同的张量，两种排序方式。每个库选择一种。

```python
# HWC:  高度, 宽度, 通道  — 磁盘、PIL、NumPy 默认
# CHW:  通道, 高度, 宽度  — PyTorch、cuDNN、大部分深度学习框架
```

CHW 的存在是因为卷积核在 H 和 W 上滑动。将通道轴放在第一位意味着每个核在每个通道上看到连续的 2D 平面，这样向量化更干净。磁盘格式保留 HWC，因为这匹配传感器输出扫描线的方式。

你将输入上千次的一行转换：

```python
chw = hwc.transpose(2, 0, 1)   # PyTorch 期望的
hwc = chw.transpose(1, 2, 0)   # 如果你想可视化
```

内存布局，可视化：

```
HWC: [行0像素0][行0像素1]...[行0像素W-1][行1像素0]...  每个像素是 [R,G,B] 连续
CHW: [所有R行][所有G行][所有B行]                          每个通道平面连续
```

### 数值范围与数据类型

三种主流约定：

| 约定 | 数据类型 | 范围 | 使用场景 |
|------------|-------|-------|------------------|
| 原始 | `uint8` | [0, 255] | 磁盘上的文件、PIL、OpenCV 输出 |
| 归一化 | `float32` | [0.0, 1.0] | 执行 `img.astype('float32') / 255` 之后 |
| 标准化 | `float32` | 大约 [-2, +2] | 减去均值并除以标准差之后 |

卷积网络是基于标准化输入训练的。ImageNet 统计量 `mean=[0.485, 0.456, 0.406]`, `std=[0.229, 0.224, 0.225]` 是 ImageNet 整个训练集上三个通道的算术均值和标准差，在 [0, 1] 归一化像素上计算。将原始 `uint8` 传入期望标准化浮点的模型是应用视觉中最常见的静默失败原因。

### 色彩空间及其存在理由

RGB 是捕获格式，但对于模型来说并不总是最有用的表示。

```python
# RGB：适合人类显示，捕获格式
# HSV：色调-饱和度-明度，用于颜色分割、调整
# YCbCr：亮度+色度，JPEG 使用
# LAB：感知均匀，用于色彩调整和风格迁移
```

对于大多数现代 CNN，你输入 RGB。你会在以下情况遇到其他空间：

- **HSV** — 经典计算机视觉代码、基于颜色的分割、白平衡。
- **YCbCr** — 读取 JPEG 内部结构、视频流水线、仅在 Y 通道上操作的超分辨率模型。
- **灰度图** — OCR、文档模型、任何颜色是噪声变量而非信号的情况。

从 RGB 得到灰度图是加权和，而不是平均，因为人眼对绿色比对红色或蓝色更敏感：

```python
gray = 0.299 * R + 0.587 * G + 0.114 * B   # 标准亮度系数
```

### 宽高比、调整大小和插值

每个模型都有固定的输入尺寸（大多数 ImageNet 分类器为 224x224，现代检测器为 384x384 或 512x512）。你的图像很少匹配。三个重要的调整大小选择：

- **调整较短边，然后中心裁剪** — 标准的 ImageNet 配方。保持宽高比，丢弃边缘像素条。
- **调整大小并填充** — 保持宽高比和每个像素，添加黑边。检测和 OCR 的标准做法。
- **直接调整为目标尺寸** — 拉伸图像。成本低，扭曲几何，对许多分类任务可以接受。

插值方法决定了当新网格与旧网格不对齐时如何计算中间像素：

```python
# 最近邻（最粗糙，但保留整数）→ 用于标签掩膜
# 双线性（平滑，速度快）→ 用于训练
# 双三次（更锐利）→ 用于显示
# 兰索斯（锐利，开销大）→ 用于高质量缩略图
```

经验法则：训练用双线性，你将查看的素材用双三次或兰索斯，任何包含整数类别 ID 的用最近邻。

## 构建它

### 步骤 1：加载图像并检查其形状

使用 Pillow 加载任意 JPEG 或 PNG，转换为 NumPy，并打印你得到的内容。为了一个可离线运行的确定性示例，合成一个。

```python
import numpy as np
from PIL import Image

# 合成一个随机 RGB 图像
img = np.random.randint(0, 256, (64, 128, 3), dtype=np.uint8)
print(f"shape: {img.shape}, dtype: {img.dtype}, range: [{img.min()}, {img.max()}]")
```

预期输出：`shape: (64, 128, 3)`, `dtype: uint8`, range `[0, 255]`。无论字节来自相机、JPEG 解码器还是合成生成器，这都是典型的磁盘表示。

### 步骤 2：拆分通道并重新排序布局

分别提取 R、G、B，然后从 HWC 转换为 PyTorch 所需的 CHW。

```python
r, g, b = img[:, :, 0], img[:, :, 1], img[:, :, 2]
print(f"R min: {r.min()}, G max: {g.max()}")

chw = img.transpose(2, 0, 1)   # (3, 64, 128)
print(f"CHW shape: {chw.shape}")
```

每个通道一个灰度平面。CHW 只是重新排列轴；当内存布局允许时，并不严格需要数据复制。

### 步骤 3：灰度图与 HSV 转换

加权和灰度图，然后手动 RGB 到 HSV 转换。

```python
gray = (0.299 * img[:,:,0] + 0.587 * img[:,:,1] + 0.114 * img[:,:,2]).astype(np.uint8)

# 使用 OpenCV 进行 HSV 转换（真实代码中你会用 cv2，但这里展示手动转换的原理）
# 简化版：将 R/G/B 归一化到 [0,1]，计算 max, min, delta，然后得到 H/S/V
```

色调以度数为单位输出，饱和度和明度在 [0, 1] 范围内。这与 OpenCV 的 `hsv_full` 约定一致。

### 步骤 4：归一化、标准化并逆操作

从原始字节到预训练 ImageNet 模型期望的精确张量，然后再返回。

```python
# 归一化到 [0, 1]
normalized = img.astype(np.float32) / 255.0

# 标准化（使用 ImageNet 统计量）
mean = np.array([0.485, 0.456, 0.406])
std  = np.array([0.229, 0.224, 0.225])
standardized = (normalized - mean) / std

# 逆操作（用于可视化）
std_back = standardized * std + mean
uint_back = (std_back * 255).clip(0, 255).astype(np.uint8)
```

每个通道的均值应接近 0，标准差接近 1。预处理/逆处理对正是每个 torchvision 的 `transforms.Normalize` 调用在底层所做的。

### 步骤 5：使用三种插值方法调整大小

在放大图像上比较最近邻、双线性和双三次，以使差异可见。

```python
# 使用 Pillow 调整大小（仅演示，实际你会用 torchvision 的 transforms）
from PIL import Image
pil_img = Image.fromarray(img)
large_nn = pil_img.resize((256, 256), Image.NEAREST)
large_bilinear = pil_img.resize((256, 256), Image.BILINEAR)
large_bicubic = pil_img.resize((256, 256), Image.BICUBIC)
```

最近邻在粗糙度上得分最高，因为它保留了硬边。双线性最平滑。双三次介于两者之间，在保持感知锐度的同时避免了阶梯状伪影。

## 使用它

`torchvision.transforms` 将以上所有内容打包成一个可组合的流水线。下面的代码完全复制了 `preprocess_imagenet` 的功能，加上调整大小和裁剪。

```python
import torchvision.transforms as T

transform = T.Compose([
    T.Resize(256),
    T.CenterCrop(224),
    T.ToTensor(),              # 除以 255 并转换为 CHW
    T.Normalize(mean=[0.485, 0.456, 0.406],
                std=[0.229, 0.224, 0.225])
])

# 用法：tensor = transform(PIL_image)
```

四个步骤，按此精确顺序：`Resize(256)` 将较短边缩放到 256；`CenterCrop(224)` 从中间取 224x224 的块；`ToTensor()` 除以 255 并将 HWC 转换为 CHW；`Normalize` 减去 ImageNet 均值并除以标准差。反转该顺序会静默地改变到达模型的输入。

## 关键术语

| 术语 | 人们说的 | 实际含义 |
|------|----------------|----------------------|
| 像素 | “一个有色的方块” | 一个网格位置上的一个光强度样本——彩色为三个数字，灰度为单个 |
| 通道 | “颜色” | 堆叠在图像张量中的并行空间网格之一；HWC 中为最后一个轴，CHW 中为第一个 |
| HWC / CHW | “形状” | 图像张量的轴顺序；磁盘和 PIL 使用 HWC，PyTorch 和 cuDNN 使用 CHW |
| 归一化 | “缩放图像” | 除以 255 使像素位于 [0, 1] 之间——必要但不充分 |
| 标准化 | “零中心化” | 每个通道减去均值并除以标准差，使输入分布与模型训练时匹配 |
| 灰度转换 | “平均通道” | 一个加权和，系数为 0.299/0.587/0.114，匹配人类亮度感知 |
| 插值 | “调整大小时如何选择像素” | 决定新网格与旧网格不对齐时输出值的规则——标签用最近邻，训练用双线性，显示用双三次 |
| 宽高比 | “宽度除以高度” | 区分“调整大小并填充”与“调整大小并拉伸”的比例 |
