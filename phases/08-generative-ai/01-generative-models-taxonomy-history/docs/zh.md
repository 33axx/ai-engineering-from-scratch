# 生成模型——分类与历史

> 每一个图像模型、文本模型、视频模型和 3D 模型都可以归入五个 buckets 之一。选错了 bucket，你就会和数学缠斗数周。选对了，该领域过去十二年的进展就会清晰地堆叠在你的脑海里。

**类型：** 学习  
**语言：** Python  
**前置知识：** 阶段 2（机器学习基础），阶段 3（深度学习核心），阶段 7 · 14（Transformer）  
**时长：** ~45 分钟  

## 问题

生成模型只做一件事：从某个未知分布 `p_data(x)` 中抽取出训练样本，然后输出看起来像是来自同一分布的新样本。无论你眯起眼睛看，人脸、句子、MIDI 文件、蛋白质结构——都是同一个问题。

难点在于 `p_data` 存在于一个拥有数百万维度的空间（一张 512x512 的 RGB 图像约有 786k 维），样本位于该空间内一个薄流形上，而你只有大约 1000 万个样本。暴力求解密度是不可能的。每个生成模型都是一种妥协，用一个困难的问题换取一个稍微不那么困难的问题。

在过去十二年里，有五个家族存活了下来。了解每个家族所做的妥协，就能明白为什么它在某些任务上表现出色，而在其他任务上则崩溃。

## 概念

![五个生成模型家族——按所建模的内容分类](../assets/taxonomy.svg)

**1. 显式密度、可计算。** 将 `log p(x)` 写成你实际上可以求和的表达式。自回归模型（PixelCNN、WaveNet、GPT）将 `p(x) = ∏ p(x_i | x_<i)` 分解。标准化流（RealNVP、Glow）将 `p(x)` 构建为对简单基函数进行可逆变换的结果。优点：精确似然、干净的训练损失。缺点：自回归推理是顺序的（长序列慢），流需要可逆架构（架构受限）。

**2. 显式密度、近似。** 从下方约束 `log p(x)`（ELBO）并优化该约束。VAE（Kingma 2013）使用带有变分后验的编码器-解码器。扩散模型（DDPM、Ho 2020）训练一个去噪器，隐式地优化一个加权 ELBO。扩散是 2026 年图像、视频和 3D 的主导骨架。

**3. 隐式密度。** 完全跳过密度；学习一个生成器 `G(z)` 来产生样本，以及一个判别器 `D(x)` 来区分真假。GAN（Goodfellow 2014）。推理快（一次前向传播），但训练时以不稳定著称。即使在 2026 年，StyleGAN 1/2/3 仍然是固定域照片级渲染（人脸、卧室）的最先进技术。

**4. 基于得分 / 连续时间。** 直接学习对数密度的梯度 `∇_x log p(x)`（得分）。Song & Ermon（2019）证明了得分匹配将扩散推广到 SDE。流匹配（Lipman 2023）是 2024-2026 年的热门：无模拟训练、更直的路径、比 DDPM 快 4-10 倍的采样。Stable Diffusion 3、Flux、AudioCraft 2 都使用流匹配。

**5. 基于离散码的令牌自回归。** 使用 VQ-VAE 或残差量化器将高维数据压缩成短序列的离散令牌，然后使用 Transformer 对令牌序列建模。Parti、MuseNet、AudioLM、VALL-E、Sora 的补丁令牌化器都使用这个方法。这是 bucket 1 加上一个学习到的令牌化器。

## 五个问题的筛选

当一篇新的生成模型论文发表时，在阅读方法部分之前，先回答这五个问题。

1. **建模的是什么？** 像素、潜在表示、离散令牌、3D 高斯分布、网格、波形？
2. **密度是显式还是隐式的？** 他们写出了 `log p(x)` 吗？
3. **采样：一次性还是迭代式？** 迭代意味着推理较慢；一次性通常意味着对抗性方法或蒸馏方法。
4. **条件：无条件、类别、文本、图像、姿态？** 这决定了损失函数和架构支撑。
5. **评估：FID、CLIP 得分、IS、人类偏好、任务准确率？** 每种方法都有已知的失败模式（见第 14 课）。

在本阶段的每节课中，你都会重新回答这五个问题。到最后，它们将成为你的本能反应。

## 动手构建

本课的代码是一个轻量级的可视化：使用三种玩具方法（核密度估计、离散直方图和近邻样本“类 GAN”生成器）从样本拟合一个一维高斯混合模型，这样你就能在一个屏幕上看到显式密度与隐式密度的区别。

运行 `code/main.py`。它从一个两模式高斯混合中抽取 2000 个样本，然后打印出：

```
explicit density (histogram): p(x in [-0.5, 0.5]) ≈ 0.38
approximate density (KDE):     p(x in [-0.5, 0.5]) ≈ 0.41
implicit (nearest-sample gen): 20 new samples printed, no p(x)
```

注意：前两种方法允许你询问“这个点的可能性有多大？”第三种方法不能。这就是 *显式与隐式* 的区别，它将在未来的每节课中都很重要。

## 实际使用

2026 年，哪个家族用于哪个任务？

| 任务 | 最佳家族 | 原因 |
|------|----------|------|
| 照片级人脸、窄域 | StyleGAN 2/3 | 仍然最锐利、推理最快。 |
| 通用文本到图像 | 潜在扩散 + 流匹配 | SD3, Flux.1, DALL-E 3。 |
| 快速文本到图像 | Rectified flow + 蒸馏 | SDXL-Turbo, SD3-Turbo, LCM。 |
| 文本到视频 | Diffusion Transformer + 流匹配 | Sora, Veo 2, Kling。 |
| 语音 + 音乐 | 基于令牌的自回归（AudioLM, VALL-E, MusicGen）或流匹配（AudioCraft 2） | 离散令牌成本低、可扩展。 |
| 3D 场景 | 高斯泼溅拟合、扩散先验 | 3D-GS 用于重建，扩散用于新视角。 |
| 密度估计（无需采样） | 流 | 唯一能精确计算 `log p(x)` 的家族。 |
| 模拟 / 物理 | 流匹配、得分 SDE | 直线路径、平滑向量场。 |

## 关键术语

| 术语 | 人们说的 | 实际含义 |
|------|----------|----------|
| 生成模型 | “它能生成新东西” | 学习 `p_data(x)` 的采样器，可选地暴露 `log p(x)`。 |
| 显式密度 | “你可以评估它” | 模型提供封闭形式或可计算的 `log p(x)`。 |
| 隐式密度 | “GAN 风格” | 只有采样器——无法评估给定点的 `p(x)`。 |
| ELBO | “证据下界” | `log p(x)` 的一个可计算下界；VAE 和扩散模型优化它。 |
| 得分 | “对数密度的梯度” | `∇_x log p(x)`；扩散和 SDE 模型学习这个场。 |
| 流形假设 | “数据在一个曲面上” | 高维数据集中在一个低维流形上；这是降维有效的原因。 |
| 自回归 | “预测下一个片段” | 将联合分布分解为条件分布的乘积。 |
| 潜在表示 | “压缩编码” | 低维表示，解码器可以从中重构输入。 |

## 生产说明：五个家族，五种推理形态

每个家族对应不同的推理服务器成本曲线。生产中的推理文献将 LLM 推理框架描述为 prefill + decode；同样的分解也适用于此处：

- **自回归（bucket 1 和 5）。** 顺序解码主导延迟；KV-cache、连续批处理和推测解码都直接适用。
- **VAE / 扩散 / 流匹配（bucket 2 和 4）。** 没有 LLM 意义上的 decode。成本 = `num_steps × step_cost`，而 `step_cost` 是在完整潜在分辨率下的一次 Transformer 或 U-Net 前向传播。生产中的旋钮包括步数（DDIM / DPM-Solver / 蒸馏）、批大小和精度（bf16 / fp8 / int4）。
- **GAN（bucket 3）。** 一次前向传播。没有调度，没有 KV-cache。TTFT ≈ 总延迟。这就是为什么 StyleGAN 在窄域 UX 上仍然胜出。

当你在论文摘要中看到“比扩散快”时，将其翻译为“更少的步数 × 相同的步成本”或“相同的步数 × 更便宜的步成本”。其他都是营销。
