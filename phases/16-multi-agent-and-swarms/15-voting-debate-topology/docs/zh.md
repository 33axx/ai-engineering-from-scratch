# 投票、自一致性与辩论拓扑

> 最廉价的聚合方式：采样 N 个独立智能体，多数投票。Wang 等人 2022 年的自一致性就是用一个模型采样 N 次实现的。多智能体通过引入**异质性**智能体（不同模型、不同提示、不同温度、不同上下文）来扩展它，以打破单一文化。除了多数投票，辩论拓扑也很重要：MultiAgentBench (arXiv:2503.01935, ACL 2025) 评估了星型/链型/树型/图型协调方式，发现**图型在研究任务中最佳**，且当智能体数量超过约 4 个时会出现“协调税”。AgentVerse (ICLR 2024) 记录了两种涌现模式——志愿者行为和从众行为——而从众既是特征（达成共识）也是风险（群体思维，第 24 课）。本课将绘制拓扑空间，构建每种变体，并测量协调税。

**类型：** 学习 + 构建
**语言：** Python (stdlib)
**先决条件：** 阶段 16 · 07 (心智社会与辩论)，阶段 16 · 14 (共识与拜占庭容错)
**时间：** ~75 分钟

## 问题

辩论可以提高准确性 (Du 等人, arXiv:2305.14325)。也可能降低准确性。辩论是否有帮助取决于四个结构选择：

1. 谁与谁对话 (拓扑)。
2. 多少轮次 (Du 2023: 轮次和智能体数量各自独立地影响结果)。
3. 智能体是否异质（不同的基础模型打破单一文化）。
4. 是否存在对抗性声音（强化论证 vs. 稻草人论证）。

那些简单地在任务上“运行 5 个智能体然后投票”的团队，其表现往往还不如单个智能体。这些失败并非随机。它们与拓扑和异质性密切相关。本课就是拓扑地图。

## 概念

### 自一致性，单模型基线

Wang 等人 2022 年 ("Self-Consistency Improves Chain of Thought Reasoning") 对同一模型进行 N 次采样（温度 > 0），并对推理路径的答案进行多数投票。在 GSM8K 上的结果：与单次贪婪解码相比，N=40 个样本能显著提升性能。自一致性是多智能体投票的单智能体前身。

局限：自一致性仅使用一个基础模型。误差在结构上是相关的。如果模型有系统性偏差，所有 N 个样本都会共享该偏差。

### 多智能体投票，异质性扩展

将 N 个样本替换为 N 个**不同**的智能体。不同的基础模型 (Claude, GPT, Llama)、不同的提示、不同的工具访问权限。好处：不相关的误差。代价：不同智能体成本不同；协调它们会增加开销。

2026 年，异质性辩论的规范名称是 **A-HMAD** —— 对抗性异质多智能体辩论。虽然尚未普遍采用，但论文中使用该术语指代“不同模型进行辩论，从而减少由单一文化崩溃引起的相关误差”。

### 四种拓扑

```
star                chain               tree                graph

    ┌─A─┐           A─B─C─D         ┌──A──┐              A───B
    │   │                           │     │              │ × │
    B   C                           B     C              D───C
    │   │                          / \   / \
    D   E                         D   E F   G           (fully connected)
```

星型：一个中心节点，所有其他节点仅与中心节点对话。相当于主管-工人模式，无旁路通信。
链型：线性，每个智能体看到前一个智能体的输出。类似流水线。
树型：层次结构，用于层次智能体系统 (第 06 课)。
图型：任意对任意通信。包括全连接团和任意有向无环图。

### 协调税 (MultiAgentBench)

MultiAgentBench (MARBLE, ACL 2025, arXiv:2503.01935) 在包含研究、编码和规划在内的任务套件上对星型、链型、树型、图型进行了基准测试。关键测量结果：

- **图型**拓扑在研究任务上获胜。信息任意对任意流动；智能体可以互相批评。
- **星型**在快速回答事实性任务上获胜。中心节点过滤并整合信息。
- **链型**在逐步流水线任务（分阶段精炼）上获胜。
- **协调税**在图型拓扑中出现在大约 4 个智能体之后。墙上时钟时间和令牌成本的增长速度快于质量。

4 个智能体的上限是经验性的，并非根本性限制。它反映了 2026 年 LLM 的上下文容量：每个智能体的上下文被其他智能体的输出填满，当每个人都能看到所有人时，添加第 N+1 个智能体的边际价值下降。

### 多智能体辩论策略 (“我们应该走向MAD吗？”)

arXiv:2311.17371 是 2023 年关于 MAD 策略的综述。关键发现被其他人重复验证：在相同预算下，与自一致性**结构相似**的 MAD 变体（独立采样 + 聚合）通常不如自一致性。当智能体真正异质且辩论具有对抗结构（一个智能体反对另一个）时，MAD 最有帮助。

### AgentVerse 涌现模式

AgentVerse (ICLR 2024, https://proceedings.iclr.cc/paper_files/paper/2024/file/578e65cdee35d00c708d4c64bce32971-Paper-Conference.pdf) 记录了多智能体辩论中即使没有显式设计也会出现的两种行为：

- **志愿者行为。** 智能体主动提供帮助（“我可以执行下一步”）而无需提示。有用：它将工作分配给最擅长子任务的智能体。
- **从众行为。** 智能体调整其立场以匹配批评者，即使批评者是错误的。这是辩论中对应讨好行为 (第 14 课) 的现象。

从众行为是为什么“辩论直到达成一致”会奖励霸凌者。有界轮次加上独立裁判可以缓解此问题。

### 异质性：实际影响准确率的旋钮

2024-2026 年实践文献中的一种模式：将 N 个智能体中的一个替换为不同基础模型，其准确率提升幅度比单纯增加 N 多 1 还要大。直观原因是单一文化——每个新的独立误差源比一个额外的相关样本更有价值。

在极限情况下，异质性胜过数量。在大多数具有清晰真实答案的任务上，三个不同的模型胜过五个相同模型的副本。

### 陪审团方法

Sibyl 框架（在 Minsky-LLM 文献中引用）形式化了“陪审团”——一组小型专业智能体，在每个阶段通过投票来完善答案。与简单的多数投票不同，陪审团有角色：一个智能体交叉检查，一个提供上下文，一个评分合理性。陪审团方法是介于简单投票（廉价，易受单一文化影响）和完整 MAD（昂贵，易受从众影响）之间的中间点。

### 投票加辩论何时占优

- 问题有真实答案（事实、数学、代码行为）。投票收敛有意义。
- 智能体可以访问不同的来源或工具（异质性可用）。
- 轮次有界（通常 2-3 轮）且有独立的裁判或验证器。
- 预算允许 3-5 个智能体。超过 5-7 个并在图型拓扑上时，协调税占主导。

### 投票加辩论何时有害

- 问题是观点型的。智能体会收敛到看起来最自信的答案，而非最正确的答案。
- 所有智能体共享同一个基础模型。单一文化使共识失去意义。
- 轮次无界。从众行为每次都赢。
- 任务简单。单个智能体在 N=5 的自一致性下更便宜且同样准确。

## 构建它

`code/main.py` 实现了：

- `run_star(agents, hub, question)` —— 中心节点轮询每个工人，聚合结果。
- `run_chain(agents, question)` —— 顺序精炼。
- `run_tree(root, children, question)` —— 层次结构，深度为 2 的聚合。
- `run_graph(agents, question, rounds)` —— 全对全辩论，有界轮次。
- 一个脚本化的异质性旋钮：每个智能体有一个 `error_bias` 表示其系统性错误倾向。
- 一个测量框架，在 N=3, 5, 7 下运行每种拓扑，并报告 (准确率, 总令牌数, 模拟墙上时钟时间)。

运行：

```
python3 code/main.py
```

预期输出：一个拓扑 × N → (准确率, 令牌数, 延迟) 的表格。在处理研究风格的任务时，图型在 N=3-5 表现最佳；星型在快速事实任务上表现最佳；图型在 N=7 时显示协调税（延迟增长快于准确率）。

## 使用它

`outputs/skill-topology-picker.md` 是一个技能，它读取任务描述并推荐拓扑 (星型/链型/树型/图型)、N (智能体数量)、异质性概况（要使用的基础模型）以及轮次限制。

## 交付它

对于任何集成系统：

- 首先从一个强基础模型开始使用 **N=5 的自一致性**。这是廉价的基线。
- 如果准确率重要，升级到 **N=3 的异质性投票**。测量增量。
- 只有当任务具有结构（研究、多步骤）且可实施有界轮次时，才升级到 **辩论拓扑**。
- 始终记录少数派集群。当少数派始终正确时，你就获得了一个多样性信号。
- 将墙上时钟时间和令牌数一起与准确率进行基准测试。“以 10 倍成本换取更好的准确率”是一个商业决策。

## 练习

1. 运行 `code/main.py`。绘制图型拓扑的协调税曲线：准确率 vs N，令牌数 vs N。曲线在哪个 N 处拐点？
2. 实现 A-HMAD：三个具有刻意不同偏置的智能体。所有偏置相同的基线与 A-HMAD 在第 14 课中的单一文化攻击相比如何？
3. 在图型拓扑中添加一个“裁判”角色，该角色不投票，仅对最终共识进行评分。这能改变涌现的从众行为吗？
4. 阅读 AgentVerse 论文 (ICLR 2024)。确定你的实现最强烈地展示了哪种涌现行为。你能通过提示改变来引发相反的行为吗？
5. 阅读 MultiAgentBench (arXiv:2503.01935) 第 4 节（拓扑实验）。使用你的测量框架，在论文中的一个任务上重现“图型在研究任务上获胜”的结果。

## 关键术语

| 术语 | 人们所说的 | 实际含义 |
|------|----------------|------------------------|
| 自一致性 (Self-consistency) | “采样 N 次，投票” | Wang 2022。单一模型，N 个温度>0 的样本，对推理路径进行多数投票。 |
| 异质性 (Heterogeneity) | “不同模型” | 不同基础模型或提示家族的集成。打破单一文化。 |
| MAD | "多智能体辩论" | 泛指智能体在一轮轮交流中交换批评的过程。参见 Du 2023。 |
| A-HMAD | "对抗性异质 MAD" | 强调不同模型+对抗结构的 MAD 变体。 |
| 拓扑 (Topology) | “谁与谁对话” | 星型、链型、树型、图型。决定信息流。 |
| 协调税 (Coordination tax) | “递减收益” | 在图型上大约超过 4 个智能体时，成本增长快于质量。 |
| 志愿者行为 (Volunteer behavior) | “未经提示的帮助” | AgentVerse 涌现模式：智能体主动承担一个步骤。 |
| 从众行为 (Conformity behavior) | “压力下同意” | AgentVerse 涌现模式：智能体与批评者保持一致。 |
| 陪审团 (Jury) | “小型专业小组” | Sibyl 风格的集成，带有角色（审查员、上下文提供者、评分者）。 |
