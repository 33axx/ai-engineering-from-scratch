# 水印 — SynthID、Stable Signature、C2PA

> 三种技术构建了2026年AI生成内容溯源体系。SynthID（Google DeepMind）——图像水印于2023年8月推出，文本+视频水印于2024年5月（Gemini + Veo），文本水印于2024年10月通过Responsible GenAI Toolkit开源，统一多模态检测器于2025年11月随Gemini 3 Pro一同发布。文本水印以不可察觉的方式调整下一个令牌的采样概率；图像/视频水印可抵御压缩、裁剪、滤镜、帧率变化。Stable Signature（Fernandez等人，ICCV 2023，arXiv:2303.15435）——微调潜扩散解码器，使每个输出包含一个固定的消息；在FPR<1e-6的条件下，裁剪（保留内容的10%）生成图像的检测率超过90%。后续研究"Stable Signature is Unstable"（arXiv:2405.07145，2024年5月）表明，微调可在保持质量的同时移除水印。C2PA——加密签名、防篡改元数据标准（C2PA 2.2 Explainer 2025）。水印与C2PA相辅相成：元数据可以被去除，但携带更丰富的溯源信息；水印在转码过程中持续存在，但携带的信息量较少。

**类型：** 构建  
**语言：** Python（stdlib，令牌水印嵌入+检测）  
**前提：** 阶段10 · 04（采样），阶段01 · 09（信息论）  
**时间：** ~75分钟  

## 学习目标

- 描述令牌级水印（SynthID文本风格）及其可检测的机制。
- 描述Stable Signature以及2024年将其破解的移除攻击。
- 阐述C2PA的角色及其与水印互补的原因。
- 描述关键局限：模型特异性信号、释义下的鲁棒性以及保持语义的攻击（arXiv:2508.20228）。

## 问题

2023-2024年，深度伪造和AI生成内容大规模进入政治和消费者领域。水印是提出的技术溯源信号：在创作时标记生成内容，之后进行检测。2025年的证据表明：没有水印是无条件鲁棒的，但与C2PA元数据分层结合后，这种组合提供了一个可用的溯源方案。

## 概念

### 文本水印（SynthID文本风格）

Kirchenbauer等人2023年的机制，由Google投入生产：

1. 在每个解码步骤中，对前K个令牌进行哈希，生成词汇表的一个伪随机划分，分为"绿色"和"红色"集合。
2. 通过向绿色logits添加δ，使采样偏向绿色集合。
3. 生成内容中包含的绿色令牌数量多于随机概率。

检测：对每个前缀重新哈希，统计生成内容中的绿色令牌数量，计算z分数。对于水印文本，z分数>0；对于人类文本，z分数≈0。

属性：
- 对读者不可察觉（δ足够小，质量损失很小）。
- 通过词汇表划分函数可检测。
- 对释义不鲁棒——重写文本会破坏信号。

SynthID文本于2024年10月通过Google的Responsible GenAI Toolkit开源。

### Stable Signature（图像）

Fernandez等人，ICCV 2023。微调潜扩散解码器，使每个生成的图像在潜表示中包含一个固定的二进制消息。通过神经解码器从潜空间进行检测。在FPR<1e-6的条件下，裁剪（保留内容的10%）生成图像的检测率超过90%。

2024年5月"Stable Signature is Unstable"（arXiv:2405.07145）：微调解码器可在保持图像质量的同时移除水印。生成后的对抗性微调成本低廉；水印的对抗鲁棒性有限。

### SynthID统一检测器（2025年11月）

与Gemini 3 Pro一同发布：一个多模态检测器，可在单个API中读取文本、图像、音频和视频的SynthID信号。统一了Google的溯源技术栈。

### C2PA

内容溯源与真实性联盟（Coalition for Content Provenance and Authenticity）。加密签名、防篡改元数据标准。C2PA 2.2 Explainer（2025）。C2PA清单记录溯源声明（谁创建、何时创建、经过哪些转换），并由创建者的密钥签名。

与水印互补：
- 元数据可以被去除；水印则不易被去除（或去除困难）。
- 元数据丰富（完整溯源链）；水印携带比特信息。
- C2PA依赖于平台采用；水印自动嵌入。

Google在搜索、广告和"关于此图片"中同时集成了两者。

### 局限

- **模型特定性。** SynthID仅对启用了SynthID的模型生成的输出加水印。未使用SynthID的模型生成的输出无水印，因此"无SynthID信号"不是真实性的证据。
- **释义。** 文本水印无法在保持语义的释义中存活。
- **转换攻击。** arXiv:2508.20228（2025年）展示了可同时破坏文本水印和许多图像水印的保持语义攻击。
- **微调移除。** 根据"Stable Signature is Unstable"，生成后的微调可移除嵌入的水印。

## 使用它

`code/main.py` 构建了一个玩具文本水印。令牌为整数0..N-1；加水印的采样偏向于哈希定义的绿色集合。检测器计算绿色令牌的z分数。你可以观察1000令牌生成物的检测结果，观察释义如何破坏信号，并测量人类文本上的假阳性率。

## 交付

本节课产出`outputs/skill-provenance-audit.md`。给定一个带有溯源声明的内容部署，审计：水印机制（如果有）、C2PA签名链（如果有）、各自的对抗鲁棒性以及每个模态的覆盖范围。

## 练习

1. 运行`code/main.py`。报告水印处理的1000令牌生成与人类撰写文本的z分数。识别在95%置信度阈值下的假阳性率。

2. 实现一个释义攻击，将30%的令牌替换为同义词。重新测量z分数。

3. 阅读Kirchenbauer等人2023年第6节关于鲁棒性的内容。为什么文本水印在释义下失效，而图像水印能经受裁剪？

4. 设计一个使用SynthID文本 + C2PA元数据的部署。描述消费者看到的溯源链。识别每个组件的一个故障模式。

5. 2024年"Stable Signature is Unstable"的结果表明微调可移除图像水印。设计一个限制该攻击的部署控制措施——例如，要求签名式发布微调后的检查点。

## 关键术语

| 术语 | 人们说的意思 | 实际含义 |
|------|-----------------|------------------------|
| SynthID | "谷歌的水印" | 跨模态溯源信号；文本、图像、音频、视频 |
| 令牌水印 | "Kirchenbauer风格" | 通过偏向采样实现的可检测文本水印，基于绿色令牌z分数 |
| Stable Signature | "图像水印" | 微调解码器水印；ICCV 2023 |
| C2PA | "元数据标准" | 加密签名、防篡改溯源元数据 |
| 释义鲁棒性 | "改写会破坏它吗" | 文本水印属性；目前有限 |
| 微调移除 | "对抗性去水印" | 通过微调解码器移除图像水印的攻击 |
| 跨模态检测器 | "统一SynthID" | 2025年11月推出的跨模态统一API |
