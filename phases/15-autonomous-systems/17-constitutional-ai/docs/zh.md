# 宪法AI与规则覆盖

> Anthropic 2026年1月22日的Claude宪法长达79页，采用CC0许可。它从基于规则的对齐转向基于理由的对齐，并建立了四层优先级层级：（1）安全与支持人类监督，（2）伦理，（3）Anthropic指南，（4）有用性。行为分为硬编码禁止（生物武器提升、CSAM）——操作员和用户无法覆盖；以及软编码默认——操作员可在规定范围内调整。2022年的原始版本（Bai等）通过自我批评和基于宪法的RLAIF训练无害性。一个坦诚的说明：基于理由的对齐依赖模型将原则推广到未预见的情况。Anthropic自己2023年的参与式实验显示，公众来源原则与企业原则之间约有50%的分歧；2026年的版本未纳入这些发现。

**类型：** 学习  
**语言：** Python（标准库，四层优先级解析器）  
**前置条件：** 阶段15·06（自动对齐研究），阶段15·10（权限模式）  
**时间：** 约60分钟  

## 问题

一个部署在现实中的智能体会看到其设计者从未见过的输入。没有一套规则列表能够覆盖所有情况。也没有一套规则列表能短到在计算压力下快速应用。实际问题是：如何让一个智能体与那些既能经受长尾案例又能快速推理的原则对齐？

基于规则的对齐（RBA）：列出每个不允许的事情。检查快，审计容易，但无法保持更新，并且经常对未预见的近似情况过度拒绝。基于理由的对齐（2026年Claude宪法）：编码原则，让模型推理。能扩展到未见案例，但审计更难，失败模式是原则误用而非遗漏规则。

2026年宪法采取了明确的中立立场。硬编码禁止——那些错误性不依赖于上下文的事情（生物武器提升、CSAM）——采用RBA：永远不允许，无论操作员或用户的指令如何。其他所有内容在四层层级内采用基于理由的对齐：安全和支持人类监督第一；伦理第二；Anthropic声明的指南第三；有用性最后。操作员可以在软编码区域内调整默认设置，但不能触及硬编码禁止。

## 概念

### 四层优先级层级

1. **安全和支持人类监督。** 最高优先级。模型优先考虑不削弱人类和Anthropic监督与纠正AI的能力。这不是“谨慎”，而是特指“不要以使人类监督变得更困难的方式行动”。
2. **伦理。** 诚实、避免伤害他人、不欺骗、不操纵。当与Anthropic指南冲突时，伦理优先于Anthropic的指南。
3. **Anthropic指南。** Anthropic决定重要的操作规范：产品范围、交互模式、何时使用何种工具。
4. **有用性。** 最低优先级。在更高优先级允许的范围内尽可能有用。

当层级冲突时，更高优先级胜出。这与Unix优先级或网络服务质量（QoS）的形态相同——这种框架旨在产生可预测的解决方案，而不是在单个轴上的最佳行为。

### 硬编码禁止 vs 软编码默认

**硬编码：**
- 生物武器 / CBRN 提升
- CSAM
- 对关键基础设施的攻击
- 在直接询问时欺骗用户关于模型身份

操作员无法覆盖这些。用户无法覆盖这些。在可能的情况下，它们在模型权重层面强制执行（RLHF / 宪法AI训练），在无法做到时，在推理层强制执行。

**软编码默认（操作员可调整）：**
- 回复长度默认值
- 主题范围（模型可以拒绝操作员部署范围之外的主题）
- 风格（正式 vs 随意）
- 工具使用模式

操作员调整发生在声明的边界内。操作员不能通过重命名来移除硬编码禁止。

### 2022年的CAI训练

最初的宪法AI（Bai等，2022）训练无害性：

1. 对一组提示生成回复。
2. 要求模型根据宪法（明确的原则）评估每个回复。
3. 根据评估修改回复。
4. 对修改后的配对进行RLAIF（来自AI反馈的强化学习）。

结果：一个在拒绝有害请求时提供原则性解释的模型，而不是全面拒绝。2026年宪法使用了这一训练的后继版本，并在显式层级层次上进行了额外的后训练。

### 基于理由的对齐能捕获和遗漏什么

**能捕获：**
- 原则明显适用的允许原语的未预期组合。
- 与禁止请求近似的新的请求。
- 依赖“你没有说X被禁止”的社会工程攻击。

**遗漏：**
- 利用原则模糊性的攻击（“用户要求这个，所以有用性说可以”）。
- 两个原则以未预期方式冲突，且层级顺序模糊的场景。
- 训练周期中原则解释的缓慢漂移（重新解释）。

### 2023年的参与式实验

Anthropic进行了2023年的实验，比较了企业编写的宪法与通过公众输入（约1000名美国受访者）生成的宪法。两种版本在大约50%的原则上一致。在分歧之处，公众来源版本在一些问题上更严格（政治内容处理），在其他问题上更宽松（AI身份自我披露）。2026年宪法未纳入公众来源的发现。这是该方法中的一个已知张力点。

### 为什么硬编码禁止是必要的

仅靠基于理由的对齐无法封闭长尾情况。一个能够诱使模型接受某个前提（例如，“我们是一个持牌生物武器研究实验室”）的攻击者常常可以通过基于案例推理的原则。硬编码禁止不会因前提框架而弯曲。它们是在对齐层的“第14课硬宪法限制”。

### 宪法在堆栈中的位置

宪法不是第14课的终止开关。它位于模型层：模型权重被训练成偏好的内容。终止开关和蜜罐令牌位于运行时层：运行时允许的内容。两者都是必需的。一个因为模型权重宽松而触发所有错误动作的运行时是运行时问题。一个因为运行时过度限制而拒绝所有正确动作的模型是运行时问题。各层覆盖不同类别的故障。

## 使用它

`code/main.py` 实现了一个最小的四层优先级解析器。该解析器接受一个提议的动作和一组原则评估（安全、伦理、指南、有用性），并返回动作、拒绝或修改后的动作。驱动程序运行一个小型案例集：明确允许、明确拒绝、硬编码禁止、跨层级的模糊案例。

## 交付它

`outputs/skill-constitution-review.md` 审计一个部署的宪法层：哪些是硬编码的，哪些是软编码的，操作员可以在哪里调整，以及四层层级是否实际作为解析顺序。

## 练习

1. 运行 `code/main.py`。确认即使有用性较高时，硬编码禁止也会触发。修改解析器，将有用性权重置于伦理之上；观察失败模式。

2. 阅读Claude宪法（公开，79页，CC0）。识别一个你认为定义不够明确的原则。写两段文字，解释具体的模糊性，并提出一个更精准的表述。

3. 为客服智能体设计一组软编码默认设置。操作员可以调整什么？操作员不能触碰什么？证明每个边界的合理性。

4. 阅读Bai等2022年CAI论文。描述一个案例，说明宪法AI的批评-修订循环可能产生比全面规则更差的结果。指出其类别。

5. Anthropic 2023年的参与式实验发现，公众与企业原则之间存在约50%的分歧。选择一个在生产部署中重要的类别（例如，政治中立性）。提出一种设计，让操作员能够表达自己的价值观，同时硬编码禁止保持不变。

## 关键术语

| 术语 | 人们怎么说 | 实际含义 |
|---|---|---|
| 宪法AI | "Anthropic的对齐方法" | 对照书面宪法进行自我批评 + RLAIF |
| 基于理由的对齐 | "原则而非规则" | 模型通过原则推理处理未见案例 |
| 硬编码禁止 | "永远不做X" | 任何操作员或用户都无法覆盖的、基于规则的禁止 |
| 软编码默认 | "操作员可调整" | 在声明边界内的行为，由操作员控制 |
| 四层层级 | "优先级顺序" | 安全 > 伦理 > 指南 > 有用性 |
| RLAIF | "AI反馈强化学习" | 奖励来自模型生成的批评的强化学习 |
| 参与式宪法 | "公众来源的原则" | 2023年Anthropic实验；与企业原则约有50%分歧 |
| 原则漂移 | "解释偏差" | 模型对固定原则文本的解读逐渐变化 |
